# Rollapp для Android

Приложение использует Kotlin, Jetpack Compose, Material 3 Expressive и Geist. На телефоне переключатель сфер и категорий расположен снизу, на широком экране — в шапке. Вход, публичный профиль, списки и группы следуют композиции мобильного сайта.

## Нативные маршруты

- Публичные профили, публичные списки, карточки желаний, календарь записи и доска объявлений. Русские и прежние ссылки можно передать через системное «Поделиться». Публичный профиль показывает доступные действия гостю и отправляет его на экран входа для записи, брони, подписки или копирования желания.
- Личный вишлист, лента, каталог брендов, предложения, магазин, выбор пункта CDEK, подтверждение покупки, заказы, баланс и история роллов.
- Редактирование имени и описания профиля, создание списка, создание и редактирование основных полей желания, исполнение и удаление. Для существующих задач и заметок доступны нативные формы. В планировании можно переключать доску, выбранный день и списки.
- Авторизованные операции используют API владельца. Чтение гостевого профиля использует production API. Отложенная покупка сохраняет ключ запроса до подтверждения, повтор использует тот же ключ.

Полное соответствие функциям сайта пока отсутствует. В частности, дополнительные настройки профиля, вложения, сложные поля и сценарии редакторов, повторяющиеся задачи, полные виды календаря, переписка, платежи по персональным предложениям, переводы и пополнение роллов ещё требуют переноса. Ссылку на внешний сайт продавца открывает системное приложение.

## Android-сессия

`ROLLAPP_ANDROID_AUTH_ENABLED=true` включает выдачу кода входа в HTTPS runtime после read-only проверки существующей схемы. В production Android-вход отключён. Одноразовый код хранится в таблице попыток с отдельным purpose, истекает через две минуты и обменивается на самостоятельную сессию после проверки PKCE S256. Подтверждение Яндекс ID происходит в системном браузере. Android хранит только зашифрованное сессионное значение с ключом Android Keystore. Запросы используют `X-Rollapp-Account` для проверки аккаунта.

## Сборка

JDK 17, Android SDK Platform 36, Build Tools 35.0.0. Минимальная версия устройства — Android 7.0 (API 24).

```sh
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:bundleRelease
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Пакет отладочной сборки — `ru.rollapp.android.debug`. При несовпадающем debug-ключе APK не обновится поверх уже установленного. Geist поставляется под SIL Open Font License, текст лицензии включён в APK.
