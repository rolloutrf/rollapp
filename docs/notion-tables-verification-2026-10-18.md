## Изменение

В меню табличного блока доступны добавление и удаление строк/столбцов,
переключение заголовков, выбор строки/столбца/всех ячеек, очистка и удаление
таблицы. CellSelection поддерживает Shift+клик. Оформление выбранных ячеек
находится в их меню: текстовая панель не закрывает соседнюю строку.
Цветовой индикатор учитывает только выбранные диапазоны; соседний столбец
остаётся неизменным. Удаление и очистка проверены по фактическому warning color.

Merge сохраняет содержимое верхней левой ячейки, split возвращает пустые
покрытые ячейки; Undo восстанавливает исходное содержимое. Это соответствует
описанному [поведению простых таблиц Notion](https://www.notion.com/help/columns-headings-and-dividers).
Используются команды установленной ProseMirror/Tiptap table extension;
отдельные изменения меню и Tab, создающий строку, отделены в истории от ввода.
Ширины столбцов перетягиваются мышью и сохраняются. Широкая таблица имеет один
внутренний горизонтальный scroll owner; текстовый rail страницы не расширяется.

GFM применяется к простым таблицам. При spans, ширинах, header column,
нескольких/вложенных блоках, разных выравниваниях и буквальном whitespace
`inline-table-markdown.js` сохраняет канонический читаемый HTML внутри Markdown.
Parser без DOM проверяет теги, атрибуты и прямоугольную сетку; повреждённая или
неподдерживаемая разметка становится буквальным текстом. Абзацы ячеек больше
не превращаются в hard breaks. API и модель четырёх ответов остаются прежними.
Обычное публичное чтение таблиц и fenced code использует общий read-only
рендерер: literal table syntax внутри code не создаёт таблицу.

Текст ячеек сохраняет Geist 18/28/400; семантические заголовки данных — 600 и
muted-поверхность. Сетка тонкая, без рамки вокруг редактора. Отзыв доступа
сбрасывает незавершённый resize и открытые меню; mouseup не сохраняет ширину.
Первоначальный read-only можно переключить в редактирование без пересоздания
документа. Save failure сохраняет полный table draft со spans/ширинами/абзацами.

## Исправленные находки

- Обычный GFM serializer терял spans, ширины, header column и структуру абзацев.
  Добавлен HTML fallback и точные round trips, включая вложенные toggle/списки/
  таблицы, код и пустые строки, закрывающие теги и неодинаковые ширины.
- HTML fallback теперь сохраняет marks также на hard break; unit сравнивает
  полный JSON для переноса строки со code/color.
- Составление merge из транзакции с уже удалёнными содержимыми приводило к
  двойному mapping и повреждённой сетке. Теперь сначала выполняется штатный
  merge, а его содержимое заменяется исходным anchor fragment в той же транзакции.
  Unit проверяет отсутствие TableMap problems после merge/split и полный Undo.
- Текстовый bubble для CellSelection перекрывал соседнюю ячейку. Структурный
  выбор теперь использует меню ячеек, а буквенное выделение — прежнюю панель.
- Палитра сначала обходила весь интервал между крайними ячейками. Теперь
  рассматриваются отдельные ranges; smoke проверяет выбранный столбец и соседа.
- Resize plugin первоначального read-only отсутствовал после смены доступа.
  Он устанавливается заранее с upstream editable guards; при отзыве сбрасывается
  active handle, отменяя незавершённую операцию.
- Скриншот после Escape раньше попадал в закрывающую анимацию. Итоговый
  screenshot ждёт фактического скрытия меню. Отдельный preview показывает меню
  на fixture с обычной таблицей; он не использует production-данные.

Старый assertion `data-inline-rich` для table-контейнера обновлён на новый HTML
fallback; точное сравнение исходного и восстановленного JSON осталось.

## Остаток цели

Отдельные hover/touch-ручки строк/столбцов, их drag/дублирование, рост сетки
за угол, фон целой ячейки, полный табличный clipboard и произвольные сочетания
с вложенными блоками ещё не прошли полную реализацию/сверку. Не проверены
реальные iOS/Telegram IME и длительные/повторные жесты resize на устройстве.
Интерактивные возрастные/стратегические accordion сохраняют прежний renderer;
их сложные блоки требуют отдельного аудита. Остальные R4–R10 остаются в матрице.
Общая цель «идентичный опыт Notion» не объявляется завершённой.
