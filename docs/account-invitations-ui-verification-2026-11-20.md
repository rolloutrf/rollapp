# Проверка панели «Инвайты» от 20.11.2026

База рабочего дерева `a93a78b63321753e6ec23bbabc62c7eeeb7e38e9`, ветка
`codex/invites-panel-20261120`. Проверялись локальные изменения компонента,
браузерного сценария и документации. Рабочее дерево содержало эти изменения.

Форма и история получили отдельные заголовки. Адрес, статус и дата занимают одну
строку списка с переносом длинного адреса. Копирование ссылки и повтор отправки
доступны в меню записи. Старые истёкшие и неудачные попытки свёрнуты. При сбое
чтения повтор доступен в общем футере, а введённый email сохраняется.

## Проверки

- `npm run test:ui` прошла. Аудит проверил 37 примитивов и 222 исходника JSX.
- `npm run test:profile` прошла на 320×568, 390×844, 768×900, 820×900, 1024×768, 1440×900, 1920×1080, 390×400 и 1440×400. Проверены клавиатурное меню, копирование и его ручной вариант, сохранение действующей ссылки после сбоя повтора, прокрутка до последней раскрытой попытки и положение футера при имитации мобильной клавиатуры. Снимки 390×844 и 1440×900 проверены в светлой и тёмной темах.
- `npm run test:member-invites` прошла. Проверены приглашения, регистрация, возврат к форме входа и показ номера участника.
- `npm run test:controls` и `npm run test:form-actions` прошли. Проверены размеры и видимые границы кнопок, положение футера, прокрутка и состояние мобильной клавиатуры.
- `npm run build` прошла. Vite сообщил о размере чанков свыше 500 КБ.
- `npm run dev:keepalive:status` подтвердил работающие API и frontend. Схема настроенной production PostgreSQL проверена в режиме verify. Локальный браузер остановился на входе, так как `/api/auth/yandex/config` возвращает `enabled: false`. Браузерные сценарии используют тестовые адреса и блокируют сетевые запросы к API.
- `npm audit` сообщил о 9 уязвимостях, `npm audit --omit=dev` о двух связанных с Zod результатах высокой серьёзности через `@ton/ton`. npm не предлагает совместимого исправления для этой ветки зависимости. [Zod](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5), [glob](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4), [minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249).
- `npm run check:comprehensive` запущена. К моменту фиксации отчёта она ещё выполнялась.
