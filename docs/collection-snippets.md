# Сниппеты коллекций

Владелец общей композиции: `collection-snippet-media.jsx` (медиа и статус), `collection-snippet-link.jsx` (внешняя ссылка), `.collection-snippet*` в `src/styles.css`, продуктовая видимость touch-ручки в `src/spacing.css`. Примитивы shadcn не переопределяются в исходных UI-файлах.

Потребители: CourseCard, ConferenceCard, CoachingSessionCard, WorkoutCard, MedicationCard. Карточки используют портретное медиа 236/286, две колонки на узком экране и четыре от 1024px. Медиа ограничивает собственное изображение; родитель не обрезает меню и keyboard focus.

- Статус — CollectionSnippetBadge на официальном Badge, caption с несжимаемой 12px иконкой и переносимым текстом. Каждая буква остаётся внутри badge. Полный статус доступен в title.
- При показанной 48px touch-ручке статус находится внизу изображения, без пересечения с hit target. Правило зависит от pointer/hover, а не только от ширины. Mouse-only скрывает ручку. Read-only не создаёт её. Drag preview сохраняет положение badge после скрытия ручки.
- Медиа показывает тематическую заглушку до загрузки, при пустом источнике и после исчерпания fallback. Каждая новая последовательность источников владеет собственным loading/error индексом; новый URL не наследует отказ предыдущего. Поздний запрос старого владельца не меняет новое изображение. Размер медиа не скачет между состояниями.
- Заголовок и короткие подписи могут иметь ellipsis, если полная строка доступна в title и native accessible name. Описание ограничено тремя строками; это намеренное сокращение. Метаданные и длинные слова переносятся без горизонтального overflow.
- Текст и меню находятся под медиа. Menu trigger — 48px, glyph — 20px. Меню и внешняя ссылка не открывают карточку и не начинают drag; Escape возвращает native focus меню. Внешняя ссылка — native anchor, отдельный target с полным доступным именем, 18/28 control role, ширина карточки и высота по содержимому от 48px.
- Read-only скрывает меню редактирования и ручку, сохраняет открытие/чтение и внешние ссылки. Busy отключает меню и ручку; не создаёт сохранений. Все операции API и реальные данные остаются во владельцах страниц.

`npm run test:snippets`: 320/390/640/767/768/820/1024/1440/1920×844, 390×400 и1440×400; mouse/touch, обе темы, все статусы пяти реальных компонентов, owner/read-only/busy, пустые необязательные сведения, длинный текст, фото/пустые/сломанные источники и восстановление. Отдельно — delayed image handoff, fallback, повторный источник, native open/menu/link/focus и реальный drag preview/cancel четырёх переставляемых семейств. Изображения — локальные тестовые SVG; все `/api/` запросы запрещены, производственная БД не подменяется. Проверка сохраняет JSON и screenshots.

`test:drag-drop` сохраняет полную матрицу reorder/group/cancel/rollback календаря и коллекций. `check:comprehensive` дополнительно проверяет остальные существующие поверхности приложения, включая Wishlist, группы, каталог, связанные сниппеты задач и формы. Отдельная проверка пяти collection-snippets не должна называться аудитом всех карточек приложения без этих расширенных этапов. CDP touch не подтверждает физическое iOS/Android устройство.
