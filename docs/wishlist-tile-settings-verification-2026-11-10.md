# Проверка настроек списка в плитке Вишлиста

10 ноября 2026 года. Базовый коммит `f55cce47e5718bc411f39cfc9436930deb152f23`. Рабочая копия была чистой до правки. Проверки запускались с незакоммиченными изменениями.

## Интерфейс

- Кнопка «⋯» в правом верхнем углу плитки открывает настройки её списка в личном Вишлисте и на странице профиля владельца.
- Шторка выезжает снизу до 768 px и справа начиная с 768 px. Она использует общий viewport и прокручиваемую область формы.
- Кнопка имеет доступное имя с названием списка. При закрытии шторки фокус возвращается на неё. Выбор списка на странице сохраняется при открытии, отмене и редактировании другой плитки.
- Проверка обнаружила, что общий адаптер открывал настройки отдельной мобильной страницей. Для редактирования список теперь явно использует шторку. Создание списка следует общему маршруту форм.

## Проверки

- Временный браузерный сценарий `node --input-type=module < /tmp/rollapp-wishlist-settings-smoke.mjs` прошёл на 320×700, 390×844, 390×400, 768×820, 820×900, 1024×768, 1440×844 и 1920×1080. Проверены личный Вишлист, профиль владельца, гость и просмотр по ссылке.
- Проверены геометрия 130×100 и 48×48 px, глиф 20 px, отсутствие пересечений с заголовком и счётчиком, независимое открытие касанием, мышью и клавиатурой, возврат фокуса, горизонтальная прокрутка и видимость поля и сохранения при имитации клавиатуры. Сохранение и удаление другой плитки проверены на временных данных. Все сетевые запросы к API в этом сценарии запрещены.
- Просмотрены снимки плиток и шторки, включая короткий экран и десктоп. Снимки сохранены в `/tmp/rollapp-wishlist-settings/`.
- Прошли `npm test` (789 прошли, один пропущен), `npm run test:ui`, `node scripts/action-rails-smoke.mjs` (90 сценариев), `npm run test:wish-groups` (16 сценариев), `ROLLAPP_SMOKE_PORT_OFFSET=710 npm run test:drag-drop` (80 сценариев) и `npm run build`.
- `npm run test:drawers` завершился успешно, 270 сценариев. Исторический `test:visual` не запускался. Изменённые проверки его локаторов прошли синтаксическую проверку `node --check scripts/visual-smoke.mjs`.
- Первый запуск расширенной проверки остановился на статическом ожидании четырёх прямых вызовов `ListTileContent`. Проверка теперь учитывает общую плитку `WishlistListTile`. - `npm run dev:keepalive:status` подтвердил работу API и frontend рабочей копии. Старт проверил существующую production-схему без миграций и очистки. В Chrome на 390 и 1440 px проверены health и перенаправление на вход. Авторизованный интерфейс проверен на изолированных props. Реальное мобильное устройство не использовалось.
- `npm audit` сообщил о 11 известных проблемах, `npm audit --omit=dev` — о трёх проблемах высокой серьёзности. Зависимости в этой правке не менялись.
