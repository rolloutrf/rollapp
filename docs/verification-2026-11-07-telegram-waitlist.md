# Список ожидания с Telegram, 7 ноября 2026

Гость на главной странице может оставить Telegram в формате `@username` или
`t.me/username`. Ссылка «Войти» ведёт на обычный вход. Подтверждение формы
означает, что заявка сохранена. Связь с заявителями ведётся вручную.

Для отключения формы и приёма заявок установите `TELEGRAM_WAITLIST_ENABLED`
в `false` в `shared/telegram-waitlist.js` и выпустите обычный релиз.
Список читается в production PostgreSQL под авторизованной ролью. Повторная
заявка с тем же именем сохраняет исходное время.

```sql
BEGIN READ ONLY;
SELECT '@' || split_part(key, ':', 2) AS telegram, value_text AS requested_at_utc
FROM application_settings
WHERE starts_with(key, 'telegram_waitlist:')
ORDER BY value_text, key;
COMMIT;
```
