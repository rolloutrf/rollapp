# Восстановление пополнений Telegram Stars

16 ноября 2026, Москва. Базовый коммит `61cca576`, ветка
`codex/rollapp-finance-system-20261116`. Целевые проверки выполнены на
дереве с изменениями Stars. `git diff --check` прошёл.

Кошелёк сохраняет исходный пакет, версию условий и UUID запроса. После
потери ответа «Найти счёт» читает запись через GET, сверяет условия и
пакет. Поиск остаётся доступен при паузе новых продаж. Пустой результат
разрешает ручной повтор создания с тем же UUID. Если запись есть, но
прямой провайдер ещё не вернул ссылку, повтор запрашивает ссылку к тому
же счёту. В режиме внешней доставки ссылка по-прежнему проходит через
очередь. После подтверждения Telegram кошелёк показывает зачисление и
обновляет баланс.

Визуальный прогон выявил устаревший маршрут выдачи сборки из скрытого
worktree. Фикстура теперь раздаёт файл относительно явного корня `dist`.
Широкая браузерная матрица обнаружила предупреждение семантики ссылки
оплаты. Ссылка использует режим `nativeButton={false}` и проверяется как
ссылка. Для теста READ ONLY использован тот же клиент до открытия
транзакции с временными записями.

процессами. Их состояние не заменяет проверку этого изменения.
