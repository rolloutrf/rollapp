# Операторская диагностика пополнений Stars и TON

16 ноября 2026, Москва. Базовый коммит `4f020405`, ветка
`codex/rollapp-finance-system-20261116`. Проверки выполнены на дереве с
изменениями операторской сверки. `git diff --check` прошёл.

Снимок сверки включает стадии пополнений обоих провайдеров. Активный счёт
Stars со ссылкой, активный счёт без ссылки, подтверждённый pre-checkout,
истечение и зачисление отображаются раздельно. Через минуту ожидания ссылки
у активного счёта Stars появляется запись внимания. Истёкший pre-checkout
тоже виден отдельно. Для TON истёкший счёт без подтверждения сохраняется
среди выставленных. В выпуск входят зачисленные пополнения.

В первом прогоне PostgreSQL определила разные типы параметра одного
тестового номера. Исправлено явное приведение к типам текста и UUID.
Рабочая схема и постоянные данные не изменялись.

Полная проверка чистого `4f020405` продолжалась на отдельном worktree. Для
нового коммита полный релизный прогон и публикация остаются открытыми.
Проверка хеша или идентификатора провайдера в этом шаге проверяет запись
Rollapp. Сверка фактической оплаты с провайдером остаётся отдельным
действием поддержки.
