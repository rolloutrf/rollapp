# Восстановление операций с картами из профиля

16 ноября 2026, Москва. Базовый коммит `38e45567`, ветка
`codex/rollapp-finance-system-20261116`. Целевые проверки выполнялись на
дереве с изменениями профиля. `git diff --check` прошёл.

В списке подарочных карт текущего аккаунта видны сохранённые запросы той же
вкладки. Запрос доступен после перезагрузки, даже если переданная карта уже
ушла из списка. Экран воспроизводит сохранённые реквизиты. Открытие не
отправляет запрос статуса, не загружает кошелёк и не повторяет операцию.
После пустого ответа повтор использует прежние параметры и UUID. Доступ к
результату по-прежнему проверяет серверный маршрут исходного участника.
Старый локальный формат без имени бизнеса остаётся читаемым.

Проверка во вложенном профиле выявила расхождение фокуса при исчезновении
кнопки исходного запроса. Экран теперь закрывается через штатное завершение
Drawer. После ухода вложенного слоя фокус возвращается на кнопку ещё
открытой операции или на область списка после подтверждения.

Схема и данные рабочей базы не изменялись. Полная проверка чистого
`38e45567` выполнялась параллельно. Ранний полный прогон на смешанном
дереве остановился на ожидании намерения группировки в Wishlist при 768 px,
сценарий `two tiles after/group`. Полный сценарий на ширине 768 px, включая этот случай, прошёл при
отдельном запуске `DRAG_WIDTHS=768 npm run test:drag-drop`. Диагностика
охватывает одну ширину.
Публикация и полный прогон для нового коммита остаются открытыми.
