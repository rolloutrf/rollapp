Проверка владельца выполнена в браузерном fixture с заблокированным сетевым API. Реальное подключение расширения, импорт в production и физическая мобильная клавиатура не проверялись. Изменение подготовлено локально.

Для выпуска пользователь явно запросил `verification=none`. Перед отправкой коммита существующая production-схема прошла `initializeRuntimeDatabase` по доверенному прямому TLS в транзакции READ ONLY с откатом. Сверены база и роль из Compose, зарезервированные имена, схема наград и резервного копирования.
