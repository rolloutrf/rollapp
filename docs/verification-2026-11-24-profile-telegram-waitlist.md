`telegram_waitlist:` из `application_settings` через закрытый GET. Список
показывает новые заявки первыми и сохраняет время первого отклика. Тест
проверяет 401 для гостя, 403 для чужого аккаунта с правом отправки инвайтов
и 200 с `private, no-store` для владельца.
