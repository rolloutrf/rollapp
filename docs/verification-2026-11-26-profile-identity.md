# Проверка фото и имени при открытии настроек профиля

Проверен код коммита `3ee9f1004f9cb656f31227f35d25b7f8e3e588b2` на базе `d35316f5f0f358ff8a15dc20897fdc721bdee507`. До правки рабочее дерево было чистым. Проверки интерфейса выполнялись в Chromium с компонентами приложения и синтетическими данными.

- На экране 393×852 px с верхней безопасной зоной 59 px портрет в вишлисте и настройках занимает один прямоугольник с левым краем на 148,5 px и верхним на 144 px и размером 96×96 px. Сравнение пикселей вокруг фото и имени при одинаковом состоянии указателя показало полное совпадение.
- Проверены фотография и инициалы. На ширинах 320, 600, 700 и 767 px длинное имя сохраняет переносы. На 1440 px сравнивались шрифт, кадрирование и расстояние от фото до имени внутри правой панели.
- Проверен вход с прокрученного вишлиста. В окне 700×1200 px после прокрутки на 150 px верх портрета оставался на отметке −37 px при переходе в настройки. Возврат восстановил прокрутку вишлиста.
- Все сценарии `test:profile` прошли в девяти размерах окна от 320×568 до 1920×1080 px, включая высоту 400 px. Дополнительные проверки сравнили переход между экранами в четырёх конфигурациях.
- Матрица `test:controls` прошла все 154 проверки в 11 размерах окна. После сбоя процесса Chromium на ширине 390 px оставшиеся ширины проверены в отдельных процессах с тем же набором сценариев.
- `npm run test:unit` — 1105 успешных проверок, две пропущены. Прошли `npm run test:ui`, `npm run test:profile-mood`, `npm run build` и `git diff --check`. Сборка предупреждает о размере чанков.
- `npm audit` сообщает о семи уязвимостях средней и двух высокой степени. При исключении dev-зависимостей остаются две высокой степени. Состав зависимостей в этой правке прежний.

Результат полного `check:release` для всего приложения на момент отчёта не зафиксирован. Физический iPhone и сохранение фотографии в рабочем аккаунте в эту проверку не входили.
