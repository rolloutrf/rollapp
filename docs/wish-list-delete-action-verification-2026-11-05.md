# Проверка кнопки удаления списка желаний, 5 ноября 2026

Базовый коммит `f55cce47e5718bc411f39cfc9436930deb152f23`. Рабочее дерево
уже содержало незакоммиченные правки профиля и их проверки. Они сохранены.

В форме редактирования списка кнопка удаления перенесена в общий нижний
`ControlBar`, справа от сохранения. На ширине 320 px полная видимая подпись
сохранения не помещалась рядом с «Назад» и корзиной. На телефоне видимая
подпись сокращена до «Сохранить», доступное имя осталось полным.
Подтверждение сохраняет предупреждение о переносе желаний в общий список.

`FORM_ACTION_CASES=wish-list-edit npm run test:form-actions` прошёл на всех
десяти размерах матрицы. Проверены расположение кнопок в одной строке,
размер 48 px, зазор 8 px, цвет удаления, открытие и отмена подтверждения,
прокрутка и положение мобильных действий при имитации клавиатуры.
Просмотрены снимки 390×400 и 1440×844. Сценарий блокирует API-запросы.
