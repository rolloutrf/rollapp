## Изменение

Вместо четырёх экземпляров редактора используется один ProseMirror document
с четырьмя защищёнными секциями. Фиксированные вопросы остаются заголовками
вне editable contentDOM; абзацы ответов редактируются прямо в странице.
Общие выделение, панель, история Undo и очередь сохранения работают между
ответами. API сохраняет прежний `{ questions: [{ title, paragraphs }] }`;
адаптер оставляет неизменённые legacy-массивы абзацев в исходном виде.

Выделение в обе стороны поддерживает Bold, Backspace/Delete, замену текста,
Enter, copy/cut и HTML paste. Вопросы и оставшиеся части ответов сохраняются
на своих местах; Undo восстанавливает весь диапазон одним действием.
Позднее подтверждение сохранения не затирает новый ввод, ошибка сохраняет
черновик всех ответов, reload восстанавливает его без автоматической записи.

Во время проверки исправлены:

- Ввод кириллицы через `beforeinput` при сквозном выделении: обработчик
  `handleTextInput` не покрывал этот браузерный путь.
- Возврат курсора стрелкой из AllSelection: теперь выбирается начало/конец
  редактируемого ответа, и панель скрывается без изменения текста.
- Форматирование при NodeSelection после drag/Undo: целый абзац больше
  не вызывает панель inline-форматирования.
- Ручка плагина, которая после изменения документа могла привязаться
  к защищённому внешнему контейнеру: такой target скрывает ручку; наведение
  на обычный абзац возвращает её к абзацу.
- Copy/cut сверяют актуальный нативный текстовый диапазон перед сериализацией.
- Нулевая computed outline-width для inline focus задана явно. Видимых рамок,
  теней и колец у текста нет; фокус кнопок панели сохранён.

Тест программного выделения предваряется настоящим кликом и двумя animation
frames: это завершает NodeSelection после drag/Undo и mount ленивого редактора,
не подменяя native selection вызовом editor-команды. Legacy CSS assertion о
`ol/li` заменён проверкой единого редактора без list-wrapper; реальные отступы
и совпадение левого края каждого ответа проверяются браузером.

## Оставшиеся ограничения

Реальные iOS/Telegram IME и клавиатура не проверены; отмена composition в smoke
синтетическая. Произвольные вложенные списки/таблицы/toggle через несколько
ответов и перенос межсекционных групп ещё не прошли полный аудит. Блочный цвет,
расширенный slash, медиа, действия над таблицами и непоследовательный выбор
остаются в общей матрице Notion. Полный аудит приложения не считается успешным:
его останавливает «Gallup DNA labels must use shrinkable grid tracks».
