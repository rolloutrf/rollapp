## Что изменено

- При наборе `> ` создаёт toggle, `" ` — цитату; a./i. распознаются как ordered list.
  Чтение/вставка сохранённого Markdown сохраняют прежние значения `>`-цитат.
- В общий выбор через +/slash/тип добавлены код, разделитель, таблица 3×3.
  Код остаётся буквальным, разделитель даёт собственный следующий абзац,
  таблица — курсор в первой ячейке и Tab по ячейкам. Соседний текст сохраняется.
- Создание и последующий ввод отменяются раздельно. Undo slash-преобразования
  возвращает целиком введённую команду. Backspace после toggle-префикса восстанавливает символы.
- Преобразование текста в toggle сохраняет marks, мягкий перенос и вложенное
  содержимое; соседние пункты/номера не теряются. Enter использует существующий
  пустой абзац body. Вложенные toggle сохраняются после Markdown reload.
- Вставка структуры после Select All корректно находит последний блок.
- Панель выделения скрывается на время выбора типа, действий блока или ввода
  ссылки и восстанавливается при отмене: она больше не перекрывает меню.

Семантические конструкторы вынесены в `inline-block-nodes.js`, чтобы вставка и
команды использовали одни и те же узлы без циклических импортов.
Явный тип ordered list зеркалируется в data-list-marker: HTML type-селекторы
не различали регистр и давали неправильное отображение. Шкала и ритм текста сохранены.
