# Футер приглашений в профиле, 14 ноября 2026

Проверяемый коммит `dcb0f305d6d8f2a23a5368c7f322cb19c51b8f1b`,
ветка `codex/business-contact-cards-20261114`. Проверки запускались с
изменениями до коммита. Основная локальная копия не менялась.

Приглашения используют `ScrollArea` и `DrawerFooter`. Поле, сообщения об
ошибках и история лежат на поверхности шторки. Нижняя кнопка принадлежит
той же HTML-форме, а мобильный футер включает «Назад».

`npm run test:profile` прошёл на девяти размерах от 320 до 1920 px.
Проверен полный сценарий отправки по Enter и кнопкой, нативная валидация
пустого email, сохранение адреса после ошибки и повтор. Отдельный прогон
проверок приглашений из той же матрицы прошёл все девять размеров с
проверками футера на 390×400 и 1440×400, видимости последней строки при
прокрутке и имитацией экранной клавиатуры. Просмотрены снимки 390×400
и 1440×900. Реальная экранная клавиатура и доставка почты не проверялись.

`npm run test:ui`, `npm run build`, `npm run test:member-invites`,
`npm run test:form-actions` и `git diff --check` прошли. `npm audit` и `npm audit --omit=dev`
вернули 8 и 2 записи соответственно. Зависимости не менялись.

Локальный предпросмотр на 5196 восстановлен через keepalive, API на 8196.
Существующая production PostgreSQL проверена в режиме `verify`. Отказ
Telegram Lockbox на локальном запуске обойдён отключением локальной
Telegram-интеграции в этом предпросмотре. Браузерные тесты использовали
изолированный транспорт.
