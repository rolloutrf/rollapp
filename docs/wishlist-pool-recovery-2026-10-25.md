# Восстановление Wishlist — 25 октября 2026

Ошибка загрузки устранена. Авторизованный `GET /api/dashboard` снова возвращает
списки, желания и группы; в настоящем production Wishlist видны карточки и ленты,
ошибка «Не удалось загрузить Вишлист» отсутствует. Ручные действия с желаниями,
создание/редактирование/удаление и сохранение тестовых данных не выполнялись.

Причина — PostgreSQL/Odyssey `53300`: общий лимит `rollapp.rollapp_app` равен20.
Четырнадцать локальных preview были настроены на pool8, один — на pool1; production
также имел pool8. Шестой параллельный запрос `/api/dashboard` отклонялся при
исчерпании общей квоты. Успешный одиночный health не показывал эту перегрузку.

Штатным guarded metadata update у текущего образа `8559466` изменён только
PG_POOL_SIZE8→2. Image/APP_VERSION, остальной Compose, IAM/VM identity guards и
startup `verify` сохранены. Схема/роль/квота managed PostgreSQL не менялись,
сессии БД не завершались, VM не перезапускалась. Приложение ставит параллельные
запросы в очередь внутри меньшего pg.Pool.

В source `2b30812` закреплены production template2 и default1 для managed dev.
Девять доступных preview имеют фактический pool1, собственные API/frontend готовы,
KeepAlive сохранён. Private env backups находятся вне Git с правами0600/0700;
остальные поля окружения сохранены. У f9a8 исправлена существовавшая коллизия API
8080 с основной копией: API8338, frontend5238. Шесть процессов с недоступными
исходными checkout не останавливались и не перенастраивались вслепую; они остаются
ограничением общего бюджета и требуют отдельной lifecycle-разборки при дальнейшем
росте числа preview. Никакие живые PID-файлы не удалялись из-за сбоя inspection.

Реальный production existing-schema verify повторно прошёл READ ONLY. Подтверждены
runtime pool2, health8559466 и отсутствие новых pool-errors в просмотренных последних
трёх минутах. Автоматические тесты/нагрузочная матрица не запускались по сохранённому
запросу пользователя; это операционное восстановление, не comprehensive PASS.

Новые настройки UI тестов личности `5f347fe` сохранены. По явному разрешению
пользователя в связанном чате согласован общий выпуск: старый run40219201016 отменён
до image/metadata, следующий run40220215550 использует2b30812 с pool2. Из этого чата
новый image rollout не запускался, production не откатывался на старые версии.
