## Поведение

- Общая форма TaskEditor (To Do, календарь, Kanban) позволяет выбрать до 50 контактов поиском по имени/компании. Выбор и удаление участников входят в черновик формы, сохраняются вместе с задачей; отмена формы не пишет данные.
- `planning_tasks.contact_ids` хранит уникальные id. API разрешает импортированные и собственные пользовательские контакты; чужие пользовательские и удалённые контакты отклоняются. Проверяется существующий доступ через default_follow_targets; после отзыва доступа новые связи запрещены, имена уже связанных контактов не возвращаются. Имена разрешаются из собственных overrides; ответ задачи содержит только id/name/company, без приватных заметок контактов.
- Раздел «Из встреч To Do» в карточке контакта читает текущие описания связанных задач с названием, датой и временем. Копии в contact_overrides.notes не создаются. Изменение описания сразу отражается при следующем открытии карточки, снятие участника/удаление встречи убирает запись. Завершённые/архивные задачи сохраняют историю; пустые описания скрыты. Серия повторений даёт одну запись.
- Личные заметки редактируются отдельно и не перезаписываются. История To Do возвращается только владельцу аккаунта; shared contacts не открывают дополнительный доступ к планированию.
- Используются существующие формы/скроллеры/типографика, без отдельной CSS-геометрии. Результаты поиска в потоке формы, без дополнительного вертикального scroller.
