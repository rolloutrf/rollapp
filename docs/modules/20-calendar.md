# 20 Календарь

[Клиент](../../src/modules/calendar/) · [Общий код](../../shared/modules/calendar/)

**В коде.** День, неделя, месяц и год, а также представление списком в модели видов. События, переход по датам, изменение времени и длительности, чтение серии повторов из общей задачи. Интерфейс работает с выбранным календарём из пространств планирования. «Календарь для бронирования» — специальный экземпляр того же интерфейса: владелец отмечает доступные интервалы кликом или протягиванием по дневной/недельной сетке, а посетитель бронирует их по публичной ссылке.

**Владение.** Представление владеет раскладкой и жестами, модели сроков и повторов принадлежат задачам. Разворачивайте повторы, затем резервируйте точные события. Записи без времени получают свободные 30-минутные слоты начиная с 10:00 на конкретный день. Если полного слота нет, оставляйте запись в списке задач без назначенного времени. Слот показа не меняет запись. Доступные интервалы бронирования и записи участников сохраняют прежний совместимый серверный контракт `profile_session_slots` / `profile_session_bookings`; календарь владеет их рабочей проекцией и не превращает их в задачи.

**Подключение.** Принимайте календарь, диапазон, задачи и команды создания/редактирования. Для экземпляра бронирования читайте и изменяйте слоты через существующий профильный API, показывайте свободный слот, запрос `pending` и подтверждённую запись в общей сетке, а публичный URL `/calendar/book` оставляйте стабильным. Запрос можно подтвердить или отклонить, подтверждённую запись — отменить; сервер профиля проверяет владельца, участника и актуальное время. Переиспользуйте календарные расчёты в разных видах. Сохраняйте локальные ключи дат. Делайте плитку перехода интерактивной целиком, со своим фокусом и независимыми вложенными действиями.

**Приёмка.** Конфликт интервалов, переход через полночь и границу месяца, повтор, дневной слот без свободного места, разметка и удаление слота бронирования, подтверждение/отклонение запроса, отмена записи, drag/resize, разница настольного и мобильного видов и реальный Back. Выполните `npm run test:calendar`, `npm run test:profile-publications`, `npm run test:notifications`, `npm run test:dates` и `npm run test:controls`.

**Доступность.** Видимая дата и содержимое события формируют имя кнопки в том же порядке, что на экране; действие перехода к сегодня и полный интервал времени передаются описанием. Интерактивные числа соседнего месяца сохраняют контраст вторичного текста. Выбранная плитка дня наследует контрастный цвет своей поверхности.

В недельной сетке время занимает одну строку. Низкая плитка ограничивает заголовок одной строкой, чтобы время оставалось над областью изменения длительности. Полный интервал остаётся в доступном описании. Storybook проверяет границы текста и ручки на восьми размерах.
