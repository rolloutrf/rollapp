# 20 Календарь

[Клиент](../../src/modules/calendar/) · [Общий код](../../shared/modules/calendar/)

**В коде.** День, неделя, месяц и год, а также представление списком в модели видов. События, переход по датам, изменение времени и длительности, чтение серии повторов из общей задачи. Интерфейс работает с выбранным календарём из пространств планирования.

**Владение.** Представление владеет раскладкой и жестами, модели сроков и повторов принадлежат задачам. Разворачивайте повторы, затем резервируйте точные события. Записи без времени получают свободные 30-минутные слоты начиная с 10:00 на конкретный день. Если полного слота нет, оставляйте запись в списке задач без назначенного времени. Слот показа не меняет запись.

**Подключение.** Принимайте календарь, диапазон, задачи и команды создания/редактирования. Переиспользуйте календарные расчёты в разных видах. Сохраняйте локальные ключи дат. Делайте плитку перехода интерактивной целиком, со своим фокусом и независимыми вложенными действиями.

**Приёмка.** Конфликт интервалов, переход через полночь и границу месяца, повтор, дневной слот без свободного места, drag/resize, разница настольного и мобильного видов и реальный Back. Выполните `npm run test:calendar`, `npm run test:dates` и `npm run test:controls`.

**Доступность.** Видимая дата и содержимое события формируют имя кнопки в том же порядке, что на экране; действие перехода к сегодня и полный интервал времени передаются описанием. Интерактивные числа соседнего месяца сохраняют контраст вторичного текста. Выбранная плитка дня наследует контрастный цвет своей поверхности.
