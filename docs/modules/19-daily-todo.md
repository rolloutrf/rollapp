# 19 Ежедневный To Do

[Клиент](../../src/modules/daily-todo/)

**В коде.** Дневной срез задач выбранного списка по дате. На десктопе лента дат, на мобильном до 768 px три верхних контрола и нижний селектор списков. Создание использует общий AddFab и TaskEditor. Отдельное хранилище задач не требуется.

**Владение.** Представление отвечает за выбор даты, показ задач и переходы. Модуль задач сохраняет изменения. Выбранный список храните в `space` URL, дату сохраняйте при смене или создании списка. Новая задача получает выбранный день и первую незавершённую колонку.

**Подключение.** Передавайте задачи, колонки, дату, активный список и обработчики из пространства планирования. Используйте `PlanningDatePicker` и `MobileFormPages` на телефоне. Оставляйте дату и задачи в одном вертикальном скроллере, последняя строка должна уходить выше FAB.

**Приёмка.** Переход через смену месяца, переключение и создание списка на выбранной дате, отмена/успех формы, прокрутка последней задачи, размеры и стабильность кнопок на мобильном и десктопе. Запускайте `npm run test:todo`, `npm run test:controls`, `npm run test:dates` и `npm run test:form-pages`.

Задачи покупок открывают карточку пересмотра с бюджетом и решениями, а задачи подписок и сопровождения открывают соответствующие карточки Вишлиста. Обычные задачи сохраняют общий редактор. Проверка: `npm run test:purchase-plan`.
