# 17 Друзья и подписки

[Клиент](../../src/modules/social/) · [Сервер](../../server/modules/social/)

**В коде.** Поиск людей, подписки, подписчики, дни рождения, [карта друзей](32-friend-map.md) и переходы к публичным профилям. `/api/people` возвращает публичные сведения, `POST /api/profile/:username/follow` меняет подписку. Сервер поддерживает начальную подписку на заданный профиль для новых аккаунтов.

**Владение.** Держите связи подписок и их направление в социальном домене. Профиль отдаёт разрешённые сведения об участнике. Подписка служит одним из входов решения о видимости списка. Только две встречные подписки образуют друга для карты; сама подписка никогда не включает геопозицию. Для бизнес-аккаунтов она разрешает отправку новых [персональных офферов](../personal-offers.md). Личные контакты и права на частную сферу имеют собственные модули.

**Подключение.** Переиспользуйте компактную строку участника и действие подписки в поиске, публичной шапке и списках. Передавайте профиль, отношение к зрителю и обработчик действия. При смене аккаунта сбрасывайте результаты и кэш отношений.

**Приёмка.** Проверьте входящий и исходящий список, пустую выдачу, повтор переключения, собственный профиль, отсутствие даты рождения и влияние подписки на доступ к списку. Используйте `npm test` и `npm run test:navigation`.
