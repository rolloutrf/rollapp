# 05 Карточка

[Клиент](../../src/modules/card/)

**В коде.** Карточки и детали желания, товара и предложения в вишлисте, каталоге, магазине и витринах. Карточка здесь означает представление объекта или товара. В соседних сферах похожие карточки отображают курсы, тренировки и связанные с задачей объекты через свои композиции.

**Владение.** Общий сниппет владеет рамкой, обложкой, радиусом, обрезкой, заголовком, ценой и поведением фокуса. Вызывающий сценарий поставляет поля, разрешённые действия и открытие деталей. Права, резервирование и покупку проверяют их серверные модули. Разметка и действия карточки деталей используют общие мобильные роли.

**Подключение.** Следуйте контракту `WishlistSnippet` и `src/components/wishlist-snippet.css` из [AGENTS.md](../../AGENTS.md) для всех товарных сниппетов. Это точка приведения фактических реализаций к общему шаблону. Вызовы `WishlistSnippet` находятся в карточке желания, каталоге и витринах. Общая таблица стилей подключена к компоненту. Сверяйте также доступное имя, полноразмерную область открытия и независимые вложенные действия.

**Приёмка.** Сравните карточку «Мои желания» с публичным списком, всеми вкладками «Товары», каталогом, магазином, бизнес-витриной и предпросмотром формы. Проверьте курсор, клавиатуру, обрезку, длинные заголовки, цену, узкий экран и действия в деталях. Запускайте `npm run test:ui`, `npm run test:details`, `npm run test:catalog-page` и `npm run test:controls`. Паритет бизнеса проверяют `npm run test:business-accounts` и `npm run test:snippets`.
