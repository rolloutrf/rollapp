# 04 Категории

[Клиент](../../src/modules/categories/) · [Сервер](../../server/modules/categories/)

**В коде.** Шесть пространств вишлиста — товары, места, события, медиа, еда и транспорт. Пользовательские списки, группы, принадлежность и порядок принадлежат соответствующему разделу. Списки образования и группы препаратов имеют собственные модели.

**Владение.** Держите идентификаторы пространств, подписи, выбор активной категории и применимость фильтров в общем контракте навигации. Членство, исключения приватности, перемещение и запись порядка оставляйте домену коллекции. Сохраняйте совместимость с желаниями, для которых пространство определяется по спискам или применяется прежнее значение по умолчанию.

**Подключение.** Передавайте выбору категории конфигурацию раздела, активное значение, доступные опции и обработчик смены. Переиспользуйте строку вишлиста для владельца и гостя через `WishListNavigation`. Все плитки этой строки берут один оттенок текущего профиля через модуль настроения; активная выделяется интенсивностью, позиция цвет не меняет. Остальные вкладки строятся по контракту их оболочки. При необходимости используйте одну модель представления пункта, сохраняя идентификаторы и API каждого домена.

**Приёмка.** Проверьте маршруты и query при смене раздела, общее и пользовательское членство, скрытие недоступного списка, переполнение строки на мобильном, пустые категории и возврат из деталей. Запускайте `npm run test:navigation`, `npm run test:page-scrollers` и `npm run test:wish-groups` для изменений соответствующих поверхностей.
