# 21 Kanban

[Клиент](../../src/modules/kanban/)

**В коде.** Именованные доски, колонки и карточки задач. Создание, переименование, перемещение и удаление колонок и задач выполняются через общее API планирования. Телефон использует вертикальные секции, широкий экран — прокрутку доски.

**Владение.** Доска владеет компоновкой, визуальным порядком, положением предпросмотра и состоянием перетаскивания. Подтверждённые изменения проходят через модуль задач. Обновляйте вид по серверному результату. Незавершённый жест остаётся временным состоянием.

**Подключение.** Передавайте доску, колонки, задачи и команды по ID. Используйте общий редактор задачи и селектор пространств. На десктопе селектор принадлежит верхнему заголовку, на телефоне — нижней навигации. Кнопка создания и скроллер карточек принадлежат одной композиции страницы.

**Приёмка.** Первая и дополнительная доска, мобильный и десктопный скролл, перенос между колонками, пустая колонка, отмена жеста, потеря захвата, ошибка сохранения и смена доски. Запускайте `npm run test:kanban`, `npm run test:controls` и затронутые проверки навигации.
