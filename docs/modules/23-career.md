# 23 Карьера

[Клиент](../../src/modules/career/) · [Сервер](../../server/modules/career/)

**В коде.** «О себе», «Домен», CV, перфоманс-ревью и индивидуальный план развития. Поддерживаются структурированные записи и импорт PDF перфоманс-ревью. Основные API `/api/career/content/:section` и `/api/career/performance/import-pdf`. Вкладка контактов подключает отдельный модуль.

**Владение.** Карьера владеет разделами, моделью CV, циклами ревью и полями ИПР. Общий редактор предоставляет текстовые поля и inline-редактирование, а импорт PDF преобразует источник в модели карьеры. Храните порядок, идентификаторы и данные исходных записей при изменениях.

**Подключение.** Передавайте странице профессиональный документ, право редактирования и узкую операцию сохранения нужного раздела. Для ИПР используйте `InlineTextField` со структурированными полями. Встраивайте раздел в чтение или предпросмотр через тот же адаптер представления. Вкладки контактов, каталога и магазина подключают свои модули.

**Приёмка.** Владелец и приглашённый читатель, старый документ, отказ сохранения с черновиком, импорт пригодного/непригодного PDF, редактирование ревью, Back и сохранение ИПР. Применяйте `npm test`, `npm run test:text-edit` и `npm run test:form-pages`.
