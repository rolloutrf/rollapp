# 10 История операций

[Клиент](../../src/modules/history/) · [Сервер](../../server/modules/history/)

**В коде.** `GET /api/rolls` отдаёт текущий кошелёк и страницы истории роллов. `GET /api/rolls/orders` отдаёт заказы пользователя с доставкой и отметкой возврата. Движения обычного кошелька видны в одной ленте вместе с покупками и возвратами. Персональный счёт и его возврат представлены переводами. Оплаты подарочной картой остаются в истории заказов и журнале карты. Обе стороны защищённой покупки видят срок проверки, закрытие, события и доступные им действия.

**Владение.** Модуль владеет чтением, пагинацией, отображением типа, статуса, даты и суммы. Источник проводок принадлежит платежам, запись заказа и команда возврата — чекауту. Снимки товара, продавца и ПВЗ используются для исторического отображения по мере доступности.

**Подключение.** Давайте кошельку ленту проводок, маршруту заказов — ленту заказов. Для общего виджета явно передавайте вид истории, страницу, состояние загрузки и разрешённое действие. После возврата перечитайте серверный результат. В кэше разделяйте владельцев и источники.

**Приёмка.** Проверяйте стабильный порядок, следующую страницу без дублей, пустое состояние, заказ с прежним снимком, возврат и отсутствие чужих операций в API и DOM. Используйте `npm test` и `npm run test:rolls:production` по [регламенту](../verification.md).
