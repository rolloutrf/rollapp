# 13 Ассистент

[Клиент](../../src/modules/assistant/) · [Сервер](../../server/modules/assistant/)

**В коде.** Рекомендации подарков на основе исполненных желаний и поиск предложений по желанию через OpenRouter и адаптеры площадок. Поиск умеет потоково обновлять результат и хранит снимок. Пользовательские настройки OpenRouter находятся в `/api/me/openrouter`. Универсальная панель чат-ассистента в текущих маршрутах отсутствует.

**Владение.** Выдача рекомендаций и поиск владеют запросом, состоянием результата и выбором доступного адаптера. Каталог поставляет товар, доступ определяет видимый контекст, а покупку или резерв подтверждает пользователь в исходном сценарии. Передавайте модели только разрешённые поля для поиска. Личный ключ OpenRouter обрабатывается на сервере, UI получает безопасный статус.

**Подключение.** Передавайте тип задачи и минимум данных объекта через адаптер. Переиспользуйте выдачу предложений в деталях желания и карточке каталога, сохраняя свои действия у вызывающего экрана. Получатель результата должен различать загрузку, частичный результат, пустую выдачу и ошибку. Обрывайте работу при смене объекта.

**Приёмка.** Доступ к конкретному желанию, отмена запроса, ошибка провайдера, повторное чтение снимка, отсутствие предложений, отключённый или личный ключ. Используйте `npm test`, `npm run test:details` и `npm run test:openrouter:production` по [регламенту](../verification.md).
