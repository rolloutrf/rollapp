# 26 Здоровье

[Клиент](../../src/modules/health/) · [Сервер](../../server/modules/health/)

**В коде.** Результаты анализов с загрузкой и просмотром PDF, группировкой показателей и динамикой. Тренировки со списками и переносом. Препараты с полями схемы и группами. API `/api/health/{lab-results,workouts,medications,medication-groups}*`.

**В актуальном выпуске.** Трекеры сна и питания используют общую модель показателей и API здоровья.

**Владение.** Модуль владеет данными анализов, тренировок и препаратов, их разбором и редакторами. Файловое чтение подчиняется правам конкретного раздела. В проекциях сохраняйте исходные единицы измерения и даты, а общие компоненты получают данные только для своего представления.

**Подключение.** Встраивайте карточку с подготовленной моделью и действиями от вызывающего сценария. Используйте общий выбор даты, формы и подтверждение удаления. История анализов использует общую плитку списка с подписью лаборатории до двух строк. Медицинские данные и PDF отдавайте только в явно разрешённых сценариях чтения.

**Приёмка.** Разбор PDF, единицы и датировка, повторное раскрытие карточки, доступ к чужому PDF, ввод и отмена форм спорта и препаратов, порядок тренировок и удаление группы. Запускайте `npm test`, `npm run test:lab-results`, `npm run test:form-pages` и `npm run test:drag-drop`.
