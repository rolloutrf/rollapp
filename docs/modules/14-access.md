# 14 Доступ и выдача прав

[Клиент](../../src/modules/access/) · [Сервер](../../server/modules/access/) · [Общий код](../../shared/modules/access/)

**В коде.** Публичные, для подписчиков, по ссылке и приватные списки. Приватные сферы с чтением владельцем или получателем по выданному разделу. Бизнес-аккаунты запрашивают доступ, владелец принимает решение. Точки входа `/api/sphere-shares/*`, `/api/business-access/*`, `/api/sphere-access-requests/*` и `/api/shared/:token`.

**Владение.** Единое решение на сервере получает субъекта из сессии, объект, владельца, секцию, операцию и применимый токен. Различайте доступ для чтения и изменение. Контакты доступны по маршруту карьеры, историческое хранение прав остаётся в scope `contacts`. Запрос доступа и выдача действительного права имеют разные состояния.

**Подключение.** Передавайте странице выданный сервером контекст владельца и режим чтения, чтобы она не предлагала недоступные действия. API проверяет каждый запрос, включая детали и файлы. Вишлист отвечает за принадлежность к списку и передаёт факты для решения доступа и публичной проекции.

[`SphereShareAction`](../../src/modules/access/sphere-share-action.jsx)
показывает действующие права в личном разделе владельца и даёт их отозвать.
Берите область и точный раздел каждого права из `SphereSharingProvider`.
Старое широкое право Вишлиста сохраняет отдельную строку для отзыва.
Новые права выдаются в ответ на явный бизнес-запрос. Каталог и подписка
используют [договорённость об офферах](../personal-offers.md).

Маршрут «Клиенты» сохраняет проверку сессии и типа аккаунта в
[оболочке бизнес-профиля](03-profile.md). Контент открывается под общей
шапкой с переходом на собственную витрину. Прямой адрес сохраняется.
Открытые клиентами разделы собраны на этой странице.
Список и шторка «Разделы и доступ» используют один снимок доступов и
запросов. При сбое шторка оставляет «Повторить». После восстановления
снимка она снова показывает доступное действие для выбранного пользователя.
Это проверяет `node scripts/business-accounts-smoke.mjs --clients-only`. Сетка и оформление карточек «Пользователи»
также используются в [каталоге бизнес-аккаунтов](16-catalog-marketplace.md).

**Приёмка.** Матрица владельца, гостя, подписчика и гостя по ссылке. Для сфер проверьте бизнес-аккаунт с выданным и отозванным правом, соседний раздел, прямой URL, файлы и попытку записи. Используйте `npm test`, `npm run test:navigation` и закрытые интеграционные сценарии по [регламенту](../verification.md).
