# 28 Медиа и импорт

[Клиент](../../src/modules/media-import/) · [Сервер](../../server/modules/media-import/) · [Общий код](../../shared/modules/media-import/)

**В коде.** Общий приём изображений и выдача через `/api/uploads/images*` и `/api/media/:id`. Распознавание карточек по ссылке через `/api/metadata`, изолированный браузерный адаптер и расширение для поддерживаемых ритейлеров. Разбор PDF выполняют домены с собственными правами и схемами. Контакты и образование имеют адаптеры фото и логотипов.

**Владение.** Общий медиа-слой владеет валидацией файлов, id/URL, чтением и безопасным владением активом. Адаптеры импорта возвращают проверенную проекцию источника. Домен назначения проверяет смысл, привязывает актив и отвечает за свои документы. При удалении используйте существующую проверку ссылок владельца и завершайтесь ошибкой, если проверка недоступна.

**Подключение.** Передавайте файл или URL и контекст сценария. Возвращайте ссылку либо типизированный результат импорта. Встроенный редактор передаёт владельца операции и освобождает только её новый неподтверждённый актив при отмене. Используйте официальные поддерживаемые входы браузерного расширения.

**Приёмка.** Размер и тип, ошибка чтения чужого защищённого файла в доменном API, замена источника во время загрузки, используемый актив и импорт неполного источника. Запускайте `npm test`, а для inline-медиа полный `npm run test:text-edit` и `npm run check:comprehensive`. Для PDF используйте проверки домена.
