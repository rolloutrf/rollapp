# 32 Карта друзей и мест

[Клиент](../../src/modules/map/) · [Сервер](../../server/modules/map/) ·
[миграция](../../scripts/migrate-friend-map.mjs)

**В коде.** Раздел `/app/friends/map` показывает на одной интерактивной карте
избранные места владельца, его свежую геопозицию и свежие координаты взаимных
друзей. Карта использует JavaScript API 3.0 Яндекс Карт. API загружается только
в отдельном same-origin `map-frame.html`; требуемый Яндексом `unsafe-eval`
разрешён в CSP этого iframe и не добавляется в CSP основного приложения.

Избранные места собираются из двух существующих источников владельца:

- `place_waitlist` — карточки, где пользователь выбрал «Жду на Роллапп»;
- активные желания пространства `places`. Координаты берутся из параметров
  ссылки Яндекс Карт или из подтверждённой карточки `place_listings` с тем же
  Yandex organization ID.

Одна организация не рисуется дважды. Карточка без подтверждённых координат
остаётся в Wishlist, а карта показывает количество таких карточек. Enrichment
мест хранит `[longitude, latitude]` внутри ссылки `yandex-maps`; обновление
существующих карточек выполняет отдельно разрешённый
`node scripts/seed-place-listings.mjs --apply`.

**Приватность.** Передача координат по умолчанию выключена. Пользователь
включает её отдельным переключателем. Сервер отдаёт точку только при взаимной
подписке, если оба участника включили шаринг и координаты моложе 10 минут.
Выключение сразу удаляет живую точку и состояние proximity. Клиент отправляет
координаты, пока открыта авторизованная страница Rollapp. Оболочка запускает
фоновую проверку согласия, когда сессия сообщает `friendMapLocationEnabled`.
Сервер выставляет этот признак при доступной схеме карты. После закрытия или
приостановки браузера точка автоматически исчезает по TTL. Сервер использует
своё время для `observed_at` и `expires_at`, не доверяя часам клиента.

Точные живые координаты `friend_map_locations` и служебное состояние
`friend_map_proximity` намеренно не входят в долгоживущую резервную копию
аккаунта. В неё входит только собственное согласие из
`friend_map_preferences`. Данные другого аккаунта никогда не экспортируются.

**Оповещения.** Радиус входа равен 1000 м. Для защиты от дрожания GPS выходом
считается расстояние 1200 м. Направленное состояние пары создаёт оповещение
только при новом входе в радиус или после протухания прежней встречи. Название
содержит имя друга и округлённое расстояние. Используется существующий inbox
`user_notifications` с `kind='custom'` и `source_id='friend-map:<id>'`; запись
создаётся только получателю, который отдельно включил proximity-оповещения.

**Подключение.** До включения production:

1. Установить схему оповещений и настроить eve по
   [инструкции](../notifications.md).
2. Выполнить read-only preflight `npm run db:migrate-friend-map`. Отдельно и
   только после проверки целевой БД применить
   `npm run db:migrate-friend-map -- --apply --database=<точное имя БД>`.
3. Создать ключ продукта JavaScript API Яндекс Карт с HTTP Referer restrictions
   для production и preview origin. Сохранить его в Lockbox под `api_key` и
   передать `YC_YANDEX_MAPS_LOCKBOX_SECRET_ID`. Для локальной разработки можно
   использовать `ROLLAPP_YANDEX_MAPS_API_KEY`.
4. Отдельно обновить подтверждённые карточки мест, чтобы в `links` попали
   координаты. Обычный release не запускает seed и миграцию.

Официальные контракты: [подключение JS API 3.0](https://yandex.com/maps-api/docs/js-api/common/quickstart.html),
[маркеры](https://yandex.com/maps-api/docs/js-api/object/markers/index.html),
[CSP Яндекс Карт](https://yandex.com/maps-api/docs/js-api/common/connection/csp.html).

**Приёмка.** Проверяйте отказ без сессии и без схемы, невзаимную подписку,
выключенный шаринг у каждой стороны, протухшую точку, вход/дрожание/выход из
радиуса, повтор после TTL, отсутствие notification worker, дедупликацию одного
места из двух источников, карточку без координат, отказ браузера в геолокации,
mobile/desktop и возврат фокуса. Используйте `npm run test:friend-map`,
`npm run test:notifications`, `npm run test:ui` и `npm run build`.
`test:friend-map` также поднимает настоящий клиент и iframe в Chromium,
подменяя только внешний runtime Яндекс Карт: проверяет загрузку ключа,
три типа маркеров, выбор друга, ссылку места и настройку оповещений.
