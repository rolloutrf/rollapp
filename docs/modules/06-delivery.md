# 06 Доставка

[Клиент](../../src/modules/delivery/) · [Сервер](../../server/modules/delivery/)

**В коде.** СДЭК предоставляет поиск города и пункта выдачи для покупки кота за роллы. `/api/delivery/cdek/cities` и `/api/delivery/cdek/points` читают сохранённый каталог. Заказ хранит подтверждённый снимок пункта. Работающая часть покрывает выбор ПВЗ. Тарифы, создание отправлений, этикетки и трекинг требуют отдельного продуктового контракта.

**Владение.** Модуль владеет каталогом, поиском, пагинацией, допустимой свежестью снимка и проверкой кода пункта. Чекаут хранит выбор до подтверждения и передаёт код. Сервер фиксирует актуальный снимок вместе с покупкой. Старые заказы читают исторический снимок.

**Подключение.** Используйте один выборщик `город → поиск → ПВЗ` в чекауте и других сценариях выбора СДЭК. Возвращайте код и сводку адреса. Смена города сбрасывает запрос адреса и пункт. В магазине поиск и карта прокручиваются внутри шторки чекаута, основные действия остаются под прокручиваемой областью. Компонент истории использует сводку адреса в режиме чтения.

**Приёмка.** Проверьте города-тёзки, поиск по коду, пагинацию, пустой и устаревший каталог, смену города, недействительный ПВЗ без списания и чтение старого заказа. Используйте `npm test`, `npm run test:cdek:production` и `npm run test:cdek:visual` по [регламенту](../verification.md).
