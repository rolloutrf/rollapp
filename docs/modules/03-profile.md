# 03 Профиль

[Клиент](../../src/modules/profile/) · [Сервер](../../server/modules/profile/) · [Общий код](../../shared/modules/profile/)

**В коде.** Настройки имени, аватара, описания, даты рождения и публикации настроения с приватной историей. Публичная шапка доступна по кириллическому адресу из имени профиля. Вход и старые ссылки могут использовать прежний username. Изменения идут через `PATCH /api/me` и `/api/me/mood`, публичное чтение — через `GET /api/profile/:username`.

**В актуальном выпуске.** Профиль также собирает публикации, календарь записи, пользовательские ссылки на вишлисты и профильные настройки Яндекс Диска.

**Владение.** Модуль владеет полями представления аккаунта и выбором того, что можно публиковать. Владелец получает настройки и историю настроения. Посетителю отдавайте только разрешённую публичную сводку. Публичный профиль собирает вкладки вишлиста, чьи правила принадлежности и приватности остаются во владении вишлиста и доступа.

**Подключение.** Переиспользуйте публичную проекцию профиля и `ProfileAvatar` в шапке, карточках продавцов и социальных списках. Передавайте действия оболочкой. Привязки и вход подключайте через модуль идентификации, загрузку аватара — через медиа.

**Панель сферы.** `PersistentProfileHero` получает общую навигацию от
оболочки и ставит её под именем и метаданными профиля. Кнопка аватара
сохраняет своё действие. Встроенная доска объявлений показывает публикации сразу
под общей навигацией профиля. [Оболочка](29-shell.md) определяет маршруты и выбор.

**Финансы.** Пункт настроек открывает [общий кошелёк](08-payments.md) без
перехода со страницы профиля. На компьютере навигация расположена над областью
прокрутки шторы; на телефоне экран пользуется обычной прокруткой документа.
Возврат из импорта или настройки лимита восстанавливает вкладку «Покупки» и фокус.

**Ключи MCP.** Экран показывает шаги настройки Streamable HTTP и команды
Codex без подстановки ключа. Выпуск по умолчанию даёт чтение; запись требует
явного выбора. См. [подключение MCP](../mcp.md).

**Подарочные карты.** Настройки подключают `ProfileGiftCards` из модуля
[лояльности](12-loyalty.md). Клик по сертификату открывает именно его;
ссылка на магазин закрывает вложенный экран перед выходом из настроек.
Проверка: `npm run test:profile` и `npm run test:gifts`.

**Внешние вишлисты.** Профиль хранит ссылки из «Поделиться» и запускает импорт
изменённых ссылок после сохранения. Кнопка обновления в футере перечитывает все
сохранённые ссылки, сохраняя черновик. Каждый источник показывает собственный
результат. Публичные ссылки читает [модуль Вишлиста](15-wishlist.md) на сервере.
Раздел «Импорт из браузера» использует расширение для избранного и личных
списков. Проверка: `npm run test:profile-wishlists`.

Раздел «Импорт из открытого списка Ozon» принимает карточки из буфера
обмена. Закладка собирает вкладку с конкретным списком после входа.
Можно также выделить карточки на странице Ozon, скопировать и вставить их
в поле Rollapp. Сохранение идёт в текущий аккаунт как приватные товары.

**Настроение.** Используйте пять цветов из общего `profile-mood.js`.
Профиль передаёт цвет отлива выбранной плитке через `profile-tile-mood.js`.
Остальные плитки остаются серыми. Владелец видит цвет своей последней
отметки, посетитель — только опубликованный цвет владельца. Нейтральная
или недоступная отметка даёт серый отлив на выбранной плитке. Фото и инициалы
не окрашиваются. В настройках «Как вы сейчас?» предлагает пять отметок.
Цвет меняется после сохранения; журнал виден только владельцу.

**Номер участника.** В персональной информации присвоенный номер использует
те же перекидные цифры, что и [табло розыгрыша](../../src/modules/profile/member-number-board.jsx).
Пять цифр выровнены по краям полей формы, без общей рамки, фона
и видимой подписи. Итог статичен, включая ведущий ноль; у табло есть доступное
имя с полным номером. До назначения номера действие «Получить номер»
открывает отдельный экран. Проверка: `npm run test:member-invites`.

**Адрес.** Для личного профиля адрес использует порядок «фамилия-имя» из поля
имени, которое заполняется в порядке «Имя Фамилия». Латиница
транскрибируется, регистр приводится к нижнему. Для названия бизнеса
сохраняется порядок слов. При совпадениях и зарезервированных маршрутах адрес
получает числовой суффикс. Текущий адрес приходит как `profileSlug`.

Адреса существующих профилей вычисляются при чтении. При регистрации или
изменении имени текущий адрес закрепляется за аккаунтом в существующей
`profile_username_aliases`. Предыдущий адрес продолжает вести на новую
страницу этого аккаунта. Фамилия, имя, адрес и прежние ссылки согласуются в
одной транзакции сохранения профиля; миграции и массовая запись не нужны.
Старые маршруты списка, желания, календаря и записи сохраняют вкладку,
параметры и якорь.

**Приёмка.** Проверяйте русскую транскрипцию, совпадающие имена, прежние ссылки,
зарезервированные пути и смену адреса из открытого профиля. Запускайте `npm test`,
`npm run test:profile`, `npm run test:profile-wishlists` и
`npm run test:profile-publications` и `npm run test:profile-mood`. После выпуска
`node scripts/check-production-profile-address.mjs <origin>` проверяет новый
адрес и перенаправления по прежнему нику.

**Доступные имена.** Общий `Avatar` представляет изображение с именем пользователя; инициалы рассчитывает `avatarInitials`. Кнопки редактирования профиля/фотографии включают видимые инициалы в своё доступное имя, чтобы голосовой ввод находил тот же элемент. Проверяйте фото и fallback, гостя/владельца и обе темы.
