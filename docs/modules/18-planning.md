# 18 Задачи и пространства

[Клиент](../../src/modules/planning/) · [Сервер](../../server/modules/planning/) · [Общий код](../../shared/modules/planning/)

**В коде.** Задачи, статусы и колонки, именованные пространства To Do, календарей и досок, связанные объекты и контакты, общая форма `TaskEditor` для создания, изменения и удаления. API `/api/planning/spaces`, `/api/planning/tasks*` и `/api/planning/columns*`.

**В актуальном выпуске.** Планирование включает заметки, группы заметок и привязки к задачам. Календарь отдельно ведёт связи с устройствами.

**Владение.** Модуль владеет задачей, принадлежностью к пространству, датой, временем и длительностью, правилом повтора и сохранением связей. Представления To Do, календаря и Kanban используют общую модель и операции. Связанные сущности запрашиваются через адаптеры их владельцев.

**Подключение.** Экран передаёт пространство, идентификатор задачи или значения новой задачи и получает результат сохранения или отмены. Переиспользуйте `TaskEditor` для всех входов и связывания из стратегии или заметок контакта. При смене владельца и площадки завершайте запросы старого контекста. Мобильный Back восстанавливает источник, сохраняя черновик при возврате из вложенного выбора.

**Приёмка.** Создание первого и дополнительного пространства, задачи без даты и времени, повтор, связи, отсутствие доступа к связанному объекту, изоляция владельца и смена места во время запроса. Используйте `npm test`, `npm run test:planning:production`, `npm run test:form-pages` и релевантные матрицы To Do, календаря и Kanban.
