# 16 Каталог и витрины

[Клиент](../../src/modules/catalog-marketplace/) · [Сервер](../../server/modules/catalog-marketplace/) · [Общий код](../../shared/modules/catalog-marketplace/)

**В коде.** Общий каталог желаний, бренды и витрины, поиск и добавление в вишлист. Есть каталог марок и моделей транспорта. Бизнес-витрины «Каталог» и «Магазин» подключаются к сферам. Магазин котов использует свой ассортимент. Маршруты API `/api/catalog*`, `/api/vehicle-catalog/*` и чтение `/api/business-marketplace/:sphere/:kind`.

**Владение.** Каталог владеет предложением как источником, его категорией, происхождением, ценой, доступностью, фильтрами и пагинацией. Членство и приватность сохранённой копии остаются в вишлисте. Подтверждение заказа находится в чекауте. При покупке в резерв витрина передаёт показанную цену и устойчивый ключ. Сервер фиксирует снимок предложения и сверяет текущую цену перед списанием. Ассистент может обогащать выдачу своим снимком предложений.

**Подключение.** Каталог и витрины используют `WishlistSnippet` и `.snippet-grid` из [модуля карточки](05-card.md). Передавайте проекцию предложения и действия открывающего сценария. Подключайте новые витрины через адаптер ассортимент → карточка → просмотр/добавление/покупка. Различайте внутренний ID товара, ID продавца, внешний ключ источника и ID желания. Обновляйте импорт через существующие проверяемые сценарии.

В личных сферах каталог брендов, магазин за роллы и предложения доступны
из [общей панели сферы](29-shell.md), когда соответствующий маршрут существует
и разрешён пользователю. Переходы сохраняют выбранную вкладку в `tab`.
В ленте, списке брендов и магазине название раздела остаётся в навигации.
В каталоге конкретного бренда сохраняется заголовок с его названием.
Магазины, каталог брендов, предложения и объявления используют
[`app-page--collection`](../container-system.md) для общей ширины всех состояний страницы.
Карточки бизнес-аккаунтов используют сетку и оформление списка
«Пользователи» из [раздела доступов](14-access.md). Слева расположены
аватар, название и @username. Цвет подложки зависит от имени пользователя.
Кнопка подписки занимает ширину нижней части карточки, отделённой линией.
Строка профиля открывает бизнес, а подписка остаётся отдельным действием.
Геометрию проверяет `scripts/business-catalog-smoke.mjs` в составе
`npm run test:business-accounts`.
Каталог показывает все бизнес-аккаунты подходящей категории, включая
продавцов с пустыми витринами. «Открыть потребности» на карточке даёт выбранному бренду
доступ к активным потребностям покупателя и возможность отправлять
[персональные предложения](../personal-offers.md). На этой же карточке согласие отзывается.
В Вишлисте раздел «Предложения» показывает персональные позиции всех сфер
и прежние рекомендации выбранного пространства. Цена, срок исполнения и
состояние покупки показаны на карточке. Из неё открываются оформление
покупки, возврат и проверка сохранённой операции.

**Приёмка.** Фильтр бренда и категории, стабильная пагинация, деактивация товара, добавление/удаление из вишлиста, сохранение атрибуции и цена в чекауте. Проверяйте отдельно общий каталог, витрину бренда, бизнес-каталог, бизнес-магазин и магазин котов. Используйте `npm test`, `npm run test:catalog-page` и `npm run test:details`.
