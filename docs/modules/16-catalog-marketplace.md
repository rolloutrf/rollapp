# 16 Каталог и витрины

[Клиент](../../src/modules/catalog-marketplace/) · [Сервер](../../server/modules/catalog-marketplace/) · [Общий код](../../shared/modules/catalog-marketplace/)

**В коде.** Общий каталог желаний, бренды и витрины, поиск и добавление в вишлист. Есть каталог марок и моделей транспорта. Бизнес-витрины «Каталог» и «Магазин» подключаются к сферам. Магазин котов использует свой ассортимент. Маршруты API `/api/catalog*`, `/api/vehicle-catalog/*` и чтение `/api/business-marketplace/:sphere/:kind`.

**Владение.** Каталог владеет предложением как источником, его категорией, происхождением, ценой, доступностью, фильтрами и пагинацией. Членство и приватность сохранённой копии остаются в вишлисте. Подтверждение заказа находится в чекауте. При покупке в резерв витрина передаёт показанную цену и устойчивый ключ. Сервер фиксирует снимок предложения и сверяет текущую цену перед списанием. Ассистент может обогащать выдачу своим снимком предложений.

**Подключение.** Давайте карточке проекцию предложения и действия открывающего сценария. Подключайте новые витрины через адаптер ассортимент → карточка → просмотр/добавление/покупка. Различайте внутренний ID товара, ID продавца, внешний ключ источника и ID желания. Обновляйте импорт через существующие проверяемые сценарии.

В личных сферах каталог брендов, магазин за роллы и предложения доступны
из [общей панели сферы](29-shell.md), когда соответствующий маршрут существует
и разрешён пользователю. Переходы сохраняют выбранную вкладку в `tab`.

**Приёмка.** Фильтр бренда и категории, стабильная пагинация, деактивация товара, добавление/удаление из вишлиста, сохранение атрибуции и цена в чекауте. Проверяйте отдельно общий каталог, витрину бренда, бизнес-каталог, бизнес-магазин и магазин котов. Используйте `npm test`, `npm run test:catalog-page` и `npm run test:details`.
