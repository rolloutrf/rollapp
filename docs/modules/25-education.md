# 25 Образование

[Клиент](../../src/modules/education/) · [Сервер](../../server/modules/education/)

**В коде.** Курсы, конференции, коучинг, пользовательские списки, группы, перенос и порядок. У курсов есть распознавание провайдера и логотип. API `/api/education/{courses,conferences,coaching-sessions,lists}*` и маршруты логотипов.

**Владение.** Образование владеет полями и правилами трёх видов записей, их списками, группами и владельцем. Подключайте общий слой группировки со своими типами. Общий drag preview отвечает за жест и геометрию. Сервер проверяет членство, границы списка и существование записи.

**Подключение.** Конфигурация секции передаёт поля, отображение карточки и клиентские операции. Используйте общие списки образования, редактор группы, оболочку формы и адаптер `CollectionSnippet`. Основные списки и открытые группы используют `.snippet-grid` Вишлиста. Для задач и витрин отдавайте компактную проекцию записи по ключу и виду.

В редакторах курса и конференции системный выбор изображения открывается
нажатием на логотип или его заглушку. Ошибка выбора видна рядом с изображением.
Сценарий проверяет `npm run test:drawers`.

**Приёмка.** Три вида записей, первая запись/список, импорты или отсутствующий логотип там, где поддерживаются, перенос и отмена, touch через drag handle, повтор сохранения и чтение приглашённым пользователем. Запускайте `npm test`, `npm run test:snippets`, `npm run test:drag-drop` и `npm run test:form-pages`.
