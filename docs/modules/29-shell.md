# 29 Оболочка приложения

[Клиент](../../src/modules/shell/)

**В коде.** Маршрутизация, переключение разделов и общая навигация, shell, desktop/mobile-композиции, управляемые формы и порталы. `ControlBar`, `AddFab`, `PageActionButton`, `ContentPageActions`, `MobileFormPages` и `MobileFormFooter` определяют переиспользуемые контракты.

**Владение.** Оболочка владеет расположением навигации, переходами, историей, ширинами, типографикой, отступами и VisualViewport. Раздел сообщает заголовок, вкладки, действия, права и маршрут возврата. Короткие URL поддоменов принадлежат общему маршрутизатору сфер. Состояние конкретной сущности остаётся в соответствующем модуле.

**Подключение.** Подключайте страницу через роли ширины и оболочки. Используйте входы общих контролов и футеров. Сохраняйте круги/пилюли 48 px, правило одного FAB, общий типографический и адаптивный контракт. Передавайте действия как callbacks, чтобы композицию можно было использовать и в отдельном экране, и в текущем маршруте.

Под именем профиля `ProfileSectionNavigation` показывает переходы внутри
текущей сферы. Сфера сообщает доступные назначения и активный маршрут.
Вкладки содержимого остаются в селекторе приложения; редактирование и создание
принадлежат текущей странице. [Правила панели](../spacing-system.md#общие-границы-горизонтальных-лент).

Успешно загруженный раздел без записей показывает общий
[`EmptyState`](../../src/modules/shell/page-feedback.jsx): пунктирную панель
по ширине контента, значок, короткий заголовок и пояснение. Эталон — магазин.
Обычная высота от 320 px; `compact` (от 160 px) предназначен для вложенной
панели или шторы. Не дублируйте название раздела, справочные ссылки и пустые
счётчики рядом с заглушкой. Оставляйте переходы между разделами, пользовательские
списки, активные фильтры с возможностью сброса и штатный FAB. Загрузка, ошибка,
ограниченный доступ и пустой рабочий редактор сохраняют свои состояния.

**Приёмка.** Матрица ширин, низкий viewport, мобильная клавиатура, Back с глубокого скролла, доступность последнего элемента и точные размеры. По изменённой поверхности используйте `npm run test:controls`, `npm run test:navigation`, `npm run test:action-rails`, `npm run test:page-scrollers`, `npm run test:form-actions` и `npm run test:form-pages`.
