# 29 Оболочка приложения

[Клиент](../../src/modules/shell/)

**В коде.** Маршрутизация, переключение разделов и общая навигация, shell, desktop/mobile-композиции, управляемые формы и порталы. `ControlBar`, `AddFab`, `PageActionButton`, `ContentPageActions`, `MobileFormPages` и `MobileFormFooter` определяют переиспользуемые контракты.

[Общие компоненты в Storybook](https://сторибук.роллапп.рф/?path=/story/rollapp-components--button-control) показывают варианты кнопок, полей и обратной связи внутри модуля оболочки.

**Владение.** Оболочка владеет расположением навигации, переходами, историей, ширинами, типографикой, отступами и VisualViewport. Раздел сообщает заголовок, вкладки, действия, права и маршрут возврата. Состояние конкретной сущности остаётся в соответствующем модуле.

**Подключение.** Подключайте страницу через роли ширины и оболочки. Используйте входы общих контролов и футеров. Сохраняйте круги/пилюли 48 px, правило одного FAB, общий типографический и адаптивный контракт. Передавайте действия как callbacks, чтобы композицию можно было использовать и в отдельном экране, и в текущем маршруте.

**Приёмка.** Матрица ширин, низкий viewport, мобильная клавиатура, Back с глубокого скролла, доступность последнего элемента и точные размеры. По изменённой поверхности используйте `npm run test:controls`, `npm run test:navigation`, `npm run test:action-rails`, `npm run test:page-scrollers`, `npm run test:form-actions` и `npm run test:form-pages`.
