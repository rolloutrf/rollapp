# 24 Контакты

[Клиент](../../src/modules/contacts/) · [Сервер](../../server/modules/contacts/)

**В коде.** Личная адресная книга во вкладке «Карьера», поиск, пагинация и подгрузка, избранное, ссылки, фотографии, заметки и связанные встречи/задачи. Точки входа `/api/contacts*`, прежний маршрут сферы перенаправляет во вкладку. Запись и фаворит принадлежат владельцу.

**Владение.** Храните профиль контакта, список ссылок, фото и порядок его представления здесь. Задачи встреч остаются в планировании и ссылаются на ID. Связь между участниками РОЛЛАПП обслуживают подписки. Доступ чтения учитывает исторический scope контактов.

**Подключение.** Переиспользуйте API карточки контакта и поиск в списке, редакторе встречи и выборе связанных объектов. Детали получают ID и режим доступа. В создании, редактировании и чтении аватар и имя выровнены по одной центральной оси, как в профиле. В режиме чтения компания находится под именем. Правый drawer на десктопе сохраняет собственный ScrollArea и отдельный ряд действий. Мобильная форма использует документный скроллер и общий footer.

**Приёмка.** Пагинация под нагрузкой, поиск, избранное, ошибки/замена фото, ссылки, встречи, права владельца и читателя, закрытие, фокус и неподвижность Back/Save/Delete при клавиатуре и прокрутке. Запускайте `npm run test:contacts`, `npm run test:contact-notes`, `npm run test:drawers` и `npm run test:form-actions`.
