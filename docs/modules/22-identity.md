# 22 Идентичность

[Клиент](../../src/modules/identity/) · [Сервер](../../server/modules/identity/) · [Общий код](../../shared/modules/identity/)

**В коде.** «4 вопроса», ценности, характер, миссия, идеальное состояние, жизненная стратегия, тезисы и принципы. Gallup, Hogan и пользовательские личностные тесты включают просмотр отчётов и управление PDF. Данные сохраняются по `/api/identity/content/:section` и `/api/identity/reports*`.

**Владение.** Модуль владеет ключами разделов, структурой личных документов и данными отчётов. Редактор предоставляет общий контракт чтения и записи Markdown. Доступ проверяет конкретную секцию и файл. Подключайте связанные задачи через планирование, сохраняя текущие интерактивные действия в страницах стратегии.

**Подключение.** Читатель получает сохранённый документ или проекцию отчёта и режим доступа. Редактор получает значение, контекст владельца и функцию сохранения. «4 вопроса» используют одну очередь документа. Встраивайте чтение стратегии и отчётов через тот же канонический адаптер, сохраняя медиа, колонки и порядок.

«Ценности» и «Характер» сохраняют отметки, снятие отметок и изменения
набора собственных пунктов при действии. Используйте
[`useIdentitySelection`](../../src/modules/identity/identity-selection.jsx)
для последовательной записи снимков, восстановления черновика по владельцу
и разделу, а также ожидания незавершённой записи при повторном открытии
раздела. При сбое сохраняйте выбор в интерфейсе и показывайте повтор записи.
Матрица `npm run test:action-rails` проверяет эти сценарии и режим чтения.

**Приёмка.** Сохранение и повторное чтение, доступ к отдельному разделу и PDF, пользовательский тест, состояние без отчёта, целостность источника, визуальный порядок и отсутствие отступа цитаты в «Тезисах» и «Принципах». Используйте `npm test`, `npm run test:identity-reports` и `npm run test:text-edit`.
