## Дополнительные сценарии действующей платформы

Сохранённые аккаунты, приглашения и переходы между приложениями принадлежат 01. Публикации и календарь записи принадлежат 03, потребности и подарочные карты — 12, помощник и сортировка — 13, заметки — 18, трекеры сна и питания — 26. Диалоги сообщений и подключение Яндекс Диска используют общие точки входа платформы.

## HTTP API

`/**` означает базовый путь и его вложенные маршруты. При пересечении семейств используйте более конкретную строку. Владение точкой входа включает композицию. Внутри неё перечислены модули, которые отвечают за отдельные операции и данные.

| Метод и путь | Владелец точки входа и зависимости |
| --- | --- |
| `/api/auth/**`, `GET /api/me` | 01 сессия и вход. 02 проверка провайдера. 03 проекция аккаунта. 12 начисление при регистрации |
| `/api/me/phone/**`, `POST /api/me/telegram/link` | 02 подтверждение и привязка |
| `PATCH /api/me`, `/api/me/mood/**`, `GET /api/profile/:username` | 03 профиль. 14 доступ и 15 сводка вишлиста для публичной страницы |
| `/api/sphere-shares/**`, `/api/sphere-access-requests/**`, `/api/business-access/**`, `GET /api/shared/:token` | 14 ранее выданные права и доступ по ссылке |
| `GET /api/people`, `POST /api/profile/:username/follow` | 17 социальные связи. 03 публичная проекция. 14 использует отношение при проверке списков |
| `GET /api/dashboard`, `/api/lists/**`, `/api/wishes/**` | 15 коллекции, группы, резервы, исполнение, заметки и копирование. 14 доступ. 12 награда при создании |
| `/api/wishes/:id/marketplace-offers/**`, `GET /api/gift-suggestions`, `/api/me/openrouter/**` | 13 поиск, результаты и настройки |
| `/api/catalog/**`, `/api/vehicle-catalog/**`, `GET /api/business-marketplace/:sphere/:kind` | 16 каталог, транспорт и бизнес-выдача. 15 и 12 участвуют в добавлении желания |
| `POST /api/metadata`, `/api/uploads/images/**`, `GET /api/media/:id` | 28 импорт, хранение и выдача медиа |
| `/api/delivery/cdek/**` | 06 поиск и выбранный ПВЗ |
| `GET /api/rolls`, `/api/rolls/recipients/**`, `/api/rolls/transfers/**` | 08 баланс и перевод. 10 лента операций в ответе кошелька |
| `/api/rolls/stars/**`, `/api/rolls/ton/**`, `/api/ton-connect/**`, `GET /tonconnect-manifest.json`, `/api/telegram/star-invoices/**` | 08 внешние платёжные адаптеры, подтверждение и worker |
| `POST /api/telegram/webhook` | 08 обработка Stars. 30 доставка обновлений и запуск Mini App через бота |

| `GET /api/rolls/orders` | 10 чтение истории заказов |
| `/api/planning/**` | 18 запись и чтение общей модели для 19, 20 и 21 |
| `/api/identity/**` | 22 разделы, отчёты и их PDF с доступом из 14 |
| `/api/career/**` | 23 документы и импорт ревью с доступом из 14 |
| `/api/contacts/**` | 24 адресная книга с доступом из 14 |
| `/api/education/**` | 25 списки, курсы, конференции, коучинг и логотипы с доступом из 14 |
