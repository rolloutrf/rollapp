# Восстановление операций с подарочными картами

16 ноября 2026, Москва. Базовый коммит `a96f607c`, ветка
`codex/rollapp-finance-system-20261116`. Целевые проверки выполнялись на
дереве с изменениями восстановления подарочных карт. `git diff --check`
прошёл.

Проверка исходного выпуска, пополнения или передачи читает журнал по аккаунту
и ключу запроса. После передачи и повторной передачи ответ не содержит
текущего остатка или владельца карты. При отсутствии записи пользователь
может вручную повторить исходный запрос с тем же ключом и реквизитами. При
новой передаче сервер сверяет подтверждённый остаток под блокировкой карты.
Если остаток изменился, передача останавливается до нового подтверждения.
Старые клиенты сохраняют совместимость с прежним телом запроса.
