# Публикация товара на витрине — 20 ноября 2026

Проверено рабочее дерево `codex/business-offers-subscriptions-20261119`
поверх `0bbe7b7fc32ac4c3cb6dcae3640e0056242bcaf2` с ранее существовавшими
незакоммиченными правками.

Редактор витрины отправляет товар активным. «Опубликовать» открывает
новую или выбранную ранее скрытую позицию. «Сохранить» обновляет опубликованную
позицию. Предпросмотр работает отдельно. Личные объявления сохраняют
свой переключатель публикации.

- `node scripts/business-profile-smoke.mjs` прошёл на всех восьми размерах
  от 320 до 1920 px, включая высоты 400 и 450 px. Проверены новый товар,
  выборочная публикация старого скрытого товара, предпросмотр,
  повтор отправки и личные объявления. Просмотрены кадры 390×844,
  390×400 и 1440×900.
- `npm run test:form-actions`, `npm run test:ui`, `npm test`,
  `npm run build` и `git diff --check` прошли. В модульных проверках
  1083 успешных теста и 2 пропуска. Сборка сообщила о чанках свыше 500 кБ.
- Полный `npm run check:comprehensive` запущен. Отчёт прогона находится
  в `/tmp/rollapp-item-publication-comprehensive.json`.
- `npm audit` получил от реестра ошибку дерева зависимостей.
  `npm audit --omit=dev` сообщил о двух проблемах высокой серьёзности
  в цепочке `@ton/ton` → `zod`. Зависимости в этой правке не менялись.

Браузерные проверки блокировали обращения к рабочему API. Production dev service
в основном рабочем дереве доступен, а маршрут витрины в его версии вернул 404.
Публикация в авторизованной production-сессии не проверялась. Правка в рабочей ветке.
