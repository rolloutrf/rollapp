## Эксплуатация и откат

Production deployment продолжает обновлять ту же VM. Не возвращать DNS
на её прямой IP автоматически: доступность этого маршрута с Mac не подтверждена.
Проверять текущий SHA через публичный домен и отдельно target state NLB.
Перед изменением target group сверять VM/subnet/internal IP; публичный вход
и сертификат не требуют копирования секретов на балансировщик.

Для сетевого отката сохранён прежний NAT и A-record `130.193.58.26`.
Возвращать A-record допустимо после проверки работоспособности старого
маршрута. Не удалять рабочий NLB до окончания TTL и проверки клиентов.
Управляемый локальный preview и production database connection оставлены
в прежнем состоянии.
