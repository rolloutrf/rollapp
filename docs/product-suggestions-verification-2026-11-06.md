## Изменение

Общий `ProductTitleInput` подключён к желаниям и редактору товаров продавца.
Источник — Wikidata, запрос после 3 символов и паузы 600 мс. Выбор меняет только
название. Свободный ввод остаётся доступен при пустом ответе, ошибке и лимите.
Сервер фильтрует результаты по товарным признакам, ограничивает запросы,
объединяет одинаковые обращения и хранит короткий кеш только в памяти.
Контракт и пределы покрытия: [product-suggestions.md](product-suggestions.md).

## Исправленные находки

- Escape при пустом списке мог закрыть всю форму. Теперь он закрывает только
  подсказки, не теряя черновик.
- Base UI присылает `input-clear` при blur без выбранного элемента.
  Поле свободного названия принимает только `input-change`; текст не очищается.
- Тест настоящей формы товара обновлён с textbox на combobox. Tab после ввода
  закрывает popup перед переходом к другим полям; исходные проверки сохранены.
  Два ранних comprehensive-прогона остановились на этих устаревших селекторах
  и взаимодействиях; они не считаются успешным полным аудитом.
- Ошибка маркера `uploadImage: (file) => request(` исправлена для продолжения
  прогона. При подготовке выпуска обнаружено готовое исправление `fc4b04f`
  в актуальном main; локальный дубликат удалён, используется исправление main.

## Живой предпросмотр

`http://127.0.0.1:5197/app/wishes`, API на 8197. Постоянный keepalive готов
и оставлен работающим. Используется настроенная production PostgreSQL:
TLS, `PG_POOL_SIZE=1`, `ROLLAPP_DATABASE_INITIALIZATION=verify`.
Startup подтвердил существующую схему без миграций и очистки.

В авторизованной форме желания реальный поиск `iPhone 16` вернул пять моделей.
Выбор `iPhone 16 Pro` поменял название; цена, ссылка и описание остались пустыми.
Переход между desktop/mobile сохранил черновик. Форма закрыта через «Назад»
без сохранения. Запрос без авторизации получает 401. Личная информация
и скриншоты реального аккаунта в репозиторий не добавлялись.

Отдельные реальные чтения через серверный модуль также вернули четыре модели
для `Samsung Galaxy S24`, а для `Nike Air Max` и `Adidas Samba` — по одному
результату. Это примеры покрытых моделей, не оценка полноты категории одежды.

## Зависимости и ограничения

`npm audit --omit=dev` — 0 уязвимостей. Полный `npm audit` — 8 существующих
находок в инструментах разработки (2 low, 4 moderate, 2 high), в деревьях
shadcn/minimatch/deepmerge и @ton/ton/zod. `npm audit fix --dry-run --json`
не предложил совместимых обновлений, устраняющих их: changed=0, removed=0,
те же 8 находок. Несовместимые обновления не применялись; зависимости
и lockfile этой задачей не менялись.

Wikidata не является федеральным каталогом всех товаров РФ: покрытие моделей
и особенно одежды неполное, наличие в продаже не подтверждается. Не проверены
аппаратная клавиатура телефона, экранный диктор и высокая многопроцессная
нагрузка. Реальная форма продажи проверена фикстурами, без записи объявления
в production. До запроса «Деплой без тестов» production deploy не выполнялся;
выпуск через `verification=none` фиксируется отдельно. Миграции и сохранение
тестовых данных не выполнялись. Операторам баз сообщения не отправлялись; массовой загрузки
каталога и платных подключений нет.
