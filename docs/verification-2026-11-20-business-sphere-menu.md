# Меню сфер бизнес-аккаунта — 20 ноября 2026

Проверено рабочее дерево `codex/business-offers-subscriptions-20261119`
поверх `0bbe7b7fc32ac4c3cb6dcae3640e0056242bcaf2` с ранее существовавшими
незакоммиченными правками.

Из меню сфер удалены блок «Доступно мне» и запрос, который загружал его
содержимое. Переходы «Вишлист» и «Клиенты» доступны из меню. Выданные права
и ссылки на разделы отображаются на странице «Клиенты» в «Открытых разделах».

Сценарий `node scripts/business-accounts-smoke.mjs --clients-only`
открывает меню бизнес-аккаунта с выданным доступом. Он проверяет состав меню,
активный пункт «Клиенты», отсутствие запроса меню за выданными правами,
закрытие по Escape и сохранение ссылки на разрешённый раздел в списке.
Сценарий прошёл на восьми размерах от 320 до 1920 px, включая 390×400.
Просмотрены снимки меню на 390 и 1440 px. Фикстуры запрещают запросы
к реальному API.

`npm run test:navigation`, `npm run test:controls`, `npm run test:ui`, сборка и `git diff --check`
прошли. Сборка сообщила о чанках свыше 500 кБ. `npm audit` вернул девять
замечаний. `npm audit --omit=dev` дважды завершился ошибкой реестра пакетов.
Зависимости в правке не менялись.

Изменение находится в рабочей ветке.
