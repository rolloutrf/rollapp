# Проверка шапки Вишлиста, 7 ноября 2026

Проверены незакоммиченные изменения в ветке `codex/remove-wishlist-business-plus`
на базе `9f9aa67768e22bddda3d9364f7a5016e55ccf4f2`. Исходное дерево было
чистым. SHA базы совпадал с ответом production `/api/healthz`.

Из шапки Вишлиста удалён «+» для открытия панели доступа. Проверка выявила,
что общий компонент доступа мог вывести вторую кнопку из контекста Вишлиста.
Обе точки входа закрыты. Контекст по-прежнему загружает входящие запросы,
которые отображаются под шапкой.

- `npm run test:profile-wishlists` прошёл на девяти размерах от 320 до 1920 px.
  Проверены входящий запрос на личном профиле, доступность QR, редактирования
  и добавления желания, отсутствие кнопки доступа в шапке и горизонтального
  переполнения. Скриншоты 390 и 1440 px просмотрены.
- `npm run test:catalog-page` прошёл на восьми размерах от 320 до 1920 px.
  Проверены селектор «Бизнес-аккаунты», переход к продавцу, пустой список и
  ошибка. Скриншоты 390 и 1440 px просмотрены. Оба UI-теста блокируют сетевой API.
- `npm run test:ui`, `npm run build` и `git diff --check` прошли. Сборка
  вывела предупреждение о размере чанков.
- `npm run dev:keepalive:status` подтвердил готовность API и фронтенда.
  Превью использует настроенный production PostgreSQL по TLS и прошло
  проверку существующей схемы в режиме `verify`. Сервис оставлен запущенным.
  В Chromium на 390 и 1440 px проверены публичный профиль с данными из API
  и перенаправление закрытых страниц на вход. Записывающие HTTP-запросы
  блокировались. Закрытый экран проверен в UI-фикстуре, проход с реальной
  авторизованной сессией и принятие запроса в production не выполнялись.
- `npm audit` сообщил о 8 предупреждениях, `npm audit --omit=dev` — о 2
  высоких через транзитивный `zod` в `@ton/ton`. npm не предложил
  автоматическое исправление для production-графа. Lockfile не изменялся.
- Unit-этап `npm run check:comprehensive` дал 963 PASS и 1 SKIP.
  Во время следующего изменения на диске закончилось место. Прогон
  остановлен на `test:snippets` с кодом 143. Отчёт
  `/tmp/rollapp-remove-wishlist-business-plus-comprehensive.json`.
