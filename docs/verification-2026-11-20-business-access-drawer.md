# Загрузка доступов в шторке клиента — 20 ноября 2026

Проверено рабочее дерево `codex/business-offers-subscriptions-20261119`
поверх `0bbe7b7fc32ac4c3cb6dcae3640e0056242bcaf2` с ранее существовавшими
незакоммиченными правками.

Шторка «Разделы и доступ» и список «Открытые разделы» используют
`GET /api/business-access/requests`. При наличии выданного права обработчик
передавал индекс массива в аргумент сериализатора, предназначенный для
справочника адресов. Развёрнутая версия `f72d935e318d3f76d32f2dfe59a4b023e3ce9210`
воспроизводит `TypeError` на точной выборке бизнеса со скриншота. Обработчик
из рабочей ветки возвращает один доступ и один запрос для той же выборки.
Проверка использовала настроенную production PostgreSQL в транзакции
`READ ONLY` с откатом.

Браузерный сценарий воспроизводит ошибку списка и шторки, нажимает
«Повторить» и проверяет восстановление ссылки выданного доступа.
Фикстура блокирует реальные API-запросы и проверяет отсутствие записи
при повторе. `node scripts/business-accounts-smoke.mjs --clients-only`
прошёл на восьми размерах, включая 390×400. `npm run test:ui`,
`node --check server/index.js` и `git diff --check` прошли.

Правка находится в рабочей ветке. Последняя проверка `/api/healthz`
подтвердила ту же развёрнутую версию.
