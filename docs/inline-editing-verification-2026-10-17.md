## Исправления и проверяемое поведение

- Нативный курсор и выделение вместо перехода в форму; никаких рамок, outline,
  ring, фонового поля или теней вокруг текста, включая активный фокус.
- Семантические заголовки и общий typeset 18/28, один gap 24px от панели к тексту.
- Markdown, списки, чек-листы, цитаты, форматирование выделения, `/` с фильтром,
  стрелками/Enter/Escape, undo/redo; вставка Markdown и Ctrl/Cmd+K.
- Панель ссылки возле выделения, возврат фокуса, запрет javascript-ссылок;
  ограничение ширины сохраняется при выставляемом Tiptap `width: max-content`.
- Настройки редактора, расширения и параметры floating menus стабильны между
  рендерами: обновление панели не должно перезаписывать нативное выделение.
- Общая последовательная очередь четырёх ответов, сохранение нового ввода во
  время запроса, ошибки и явный повтор, восстановление owner-scoped черновика.
- Открытие документа не сохраняет его. Исправлен `setEditable`, который без
  `emitUpdate: false` инициировал лишний onUpdate при монтировании.
- Пустой ответ разрешён схемой API; readonly/loading/access guards не сохраняют.
- Markdown round trips сохраняют текст, структуру и форматирование имеющихся
  документов, включая `:::label`/`:::statement`, ссылки, таблицы, изображения, код.

## Живая проверка и данные

Постоянный dev-service PID 52615: frontend/API готовы, настроенная production
PostgreSQL по TLS; сервис оставлен работающим. Живой UI проверен в имеющейся
сессии: 390px (редактор 358px) и 1440px (редактор 768px), documentWidth равен
viewport, outline none, border 0px, box-shadow none. Временный viewport сброшен.

При раннем открытии живого «О себе» до исправления `setEditable` произошло
непреднамеренное сохранение нормализованного Markdown. Метаданные production
показали `updated_at=2026-10-17T09:55:08.838Z`. Последующее чтение подтвердило:
текст без учёта пробелов совпадает с исходником после преобразования прежним
редактором AboutMe (он удалял нумерацию заголовков); текущий Markdown round trip
сохраняет текст. Не было снимка записи непосредственно до открытия, поэтому
побайтовую неизменность утверждать нельзя. Откат не выполнялся, чтобы не
перезаписать пользовательские изменения. После исправления проверка открытия
требует ноль сохранений; повторное чтение метаданных не выявило новой записи.

не заменяет эту проверку. Живой полный проход всех незатронутых разделов,
платежи и загрузки файлов не выполнялись.
