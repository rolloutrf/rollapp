## Проверки macOS

- `npm run build:macos` собрала `dist-macos/Rollapp.app` и `dist-macos/Rollapp.dmg`. Проверены контрольная сумма DMG, монтирование только для чтения, ссылка на Applications, совпадение бинарника в DMG и `.app`, `Info.plist` и `codesign --verify --strict`. `lipo` подтвердил `arm64` и `x86_64`, `vtool` показал минимальную версию 12.0 в обеих архитектурах.
- `.app` запущен на Apple Silicon с macOS 26.6.2. В нативном окне просмотрены экран входа Rollapp и форма `passport.yandex.ru`. Проверены системное меню, «Назад» и обновление. Отдельный живой прогон подтвердил реальный переход с Rollapp на форму Яндекс ID в итоговом коде и оба направления системной истории.
- `npm run test:macos` прошла проверку точных HTTPS-источников, истории и редиректов WebKit, геометрии экрана входа при 320×844, 390×844, 390×400, 768×844, 820×844, 1024×768, 1440×844 и 1920×844, а также восстановления при имитации ошибки сети. Изменение размеров проверено через реальный DOM WebKit. Визуально просмотрено широкое окно.
- Проверка OAuth дошла до формы поставщика. Операции авторизованного пользователя, сохранение сессии после входа, скачивание и загрузка файлов, запуск на физическом Intel Mac и на macOS 12 остаются непроверенными. Подпись локальная, Apple Developer ID и нотарификация не применялись.
