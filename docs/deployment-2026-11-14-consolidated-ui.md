## Выкладка

По запросу пользователя [полный повторный прогон](https://github.com/rolloutrf/rollapp/actions/runs/43613837378)
отменён до обновления VM. Деплой запущен через `workflow_dispatch` с
`verification=none`. Docker собрал образ под полным SHA, обновление VM
завершилось, а production health подтвердил новый SHA в 20:41 МСК.
Автоматический шаг завершился по сетевому тайм-ауту после подтверждения
версии. Повторные запросы подтвердили health, ответ 401 от MCP без
авторизации, конфигурацию Яндекс Диска и канонические редиректы доменов
и старых путей профиля. Пропущенный шаг Telegram выполнен штатным
`npm run telegram:configure`. Подтверждены Main Mini App, адрес меню
и режим long polling.

Публичная витрина и вход в подарочные карты проверены на восьми размерах
от 320 до 1920 px, включая 390×400. На сайте доступен ZIP RULAB 1.3.0.
Авторизованные сценарии покрыты локальными проверками, без записи тестовых
данных в production. Полная матрица CI для выпущенного SHA не завершена.
