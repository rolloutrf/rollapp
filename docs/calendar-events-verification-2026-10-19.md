## Исправления

- Короткая карточка сжимала название до нуля, оставляя время и ручку resize. Теперь события короче часа используют строку с началом и названием в общей caption-типографике; ручка находится справа. В длинной карточке заголовок не сжимается до нуля.
- Событие на 15 минут растягивалось до 30, создавая ложные пересечения. Layout сохраняет разрешённые API 15 минут; соседние четвертьчасовые события получают полную ширину.
- Открытие задачи без времени превращало её в 00:00 / 1440 минут. Редактор сохраняет пустое время и исходную длительность. Календарь передаёт исходную запись, а не расчётный получасовой слот. Повтор открывает исходную серию.
- Выделение времени и resize теперь отменяются через Escape, потерю pointer capture, blur, смену периода и browser Back. Отмена перед календарной навигацией выполняется синхронно, до изменения URL: ранее отпускание мыши могло сохранить старый жест после смены даты. Capture освобождается только у подключённого DOM-владельца.
- После отмены подавляется клик того же жеста, без таймера на 150 мс. Следующий отдельный клик и клавиатурная активация работают. Во время сохранения слоты не создают новую форму.
- Dev proxy учитывает отдельный PORT, сохраняя 8080 по умолчанию.

Полные navigation / form-pages / text-edit **не подтверждены**. После исправления
мгновенного scroll навигация остановилась на загрузке страницы 390 px. Form-pages
остановилась на `scrollIntoViewIfNeeded` в форме события 640 px; эта конкретная пара
сценариев впоследствии прошла отдельно. Полный text-edit пробовался с Chrome 155 и
официальным Headless Shell 149; оба прогона остановились на загрузке fixture,
последний — после 5 image-resize PASS. Это не полный редактор и не 375 PASS.

Восемь comprehensive-попыток сохранены в `calendar-events-comprehensive-attempt*.json`.
Остановки: загрузка year на 1920 px; занятый чужой порт; unit wall-clock assertion
`<500ms` при load average >200; screenshot / browser.close; анимированный toast /
popup; загрузка страницы в Headless Shell. Последний запуск с временным
`caffeinate -i` тоже оборвался на загрузке detail page. **Причина всех тайм-аутов
не установлена.** Общего зелёного релизного результата нет.

Для дополнительных этапов сохранён `calendar-events-expanded-2026-10-19.json`:
он отражает первоначальные индивидуальные прогоны, а не comprehensive PASS.
Последующие успешные action rails / catalog / wish groups указаны выше отдельно.

## Среда и безопасность данных

Локальные `.env` / `.env.local` взяты из основного checkout, не включены в diff.
Для этой копии выделены frontend 5188 и API 8088. Постоянный launchd-сервис оставлен
включённым; финальная проверка подтверждает готовность API и frontend. Использованы
настроенный production PostgreSQL по TLS, direct mode и startup `verify`.
Инициализация, миграции, backfill и очистка пользовательских записей не выполнялись.
Production integration проверяет точные database/role и делает BEGIN → ROLLBACK.

Живой UI с production API: день, неделя, месяц (42 дня), год (12 месяцев), открытие
формы на 02.10.2026 и отмена. Сохранения и удаления пользовательских событий не
выполнялись. На этой дате в доступной сессии нет событий: исходное 135-минутное
событие скриншота не изменялось; исчезновение названий воспроизведено на коротких
карточках fixture.

Browser smoke при занятом предпочтительном порте выбирают свободный и строят URL
из фактического адреса собственного сервера. Чужие тестовые серверы не останавливались.
Для controls / details / form-actions подключён существующий общий launcher.
Три осиротевших crash-handler/updater процесса этой проверки завершены только после
сверки cwd, PPID, времени запуска и парных Unix sockets; пользовательские браузеры
не затрагивались. `ROLLAPP_TEST_CONCURRENCY=1` ограничивал только параллелизм unit,
не список тестов. Критерии геометрии, пикселей и матрицы не ослаблены. В fixture
программная прокрутка перед немедленным измерением стала явно `instant`.

`npm audit` и `npm audit --omit=dev` выполнены до и после совместимого обновления
lockfile shadcn 4.22.0 → 4.22.1. Production: **0** уязвимостей; dev: **7 high**
в цепочке shadcn → fast-glob / micromatch / braces. Исправленной версии braces
[нет в GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).
Несовместимый откат shadcn до 1.0.0 не выполнялся.
