# Размеры контейнеров Rollapp

Единый источник — `src/containers.css`; интервалы и боковые поля — `src/spacing.css`. Для страниц размеры обозначают доступную ширину содержимого: оболочка добавляет боковые поля один раз. Для панели указан внешний размер примитива вместе с его внутренними полями.

shadcn/typeset прямо оставляет максимальную ширину за компоновкой приложения. Поэтому ниже — выбранные для Rollapp роли на стандартной шкале Tailwind, а не вымышленная обязательная шкала shadcn. [Typeset](https://ui.shadcn.com/docs/typeset), [Tailwind max-width](https://tailwindcss.com/docs/max-width).

| Роль | Токен | Размер | Применение |
| --- | --- | --- | --- |
| Компактная | `--layout-compact-width` | md · 28rem · 448px | Авторизация, короткий редактор списка, просмотр желания |
| Форма / список людей | `--layout-form-width` | xl · 36rem · 576px | Друзья; панели контакта, профиля, курса, конференции, коучинга, тренировки, препарата, доступа и создания желания |
| Чтение | `--layout-text-width` | 3xl · 48rem · 768px | Миссия, стратегия, четыре вопроса, тезисы, о себе, домен, ИПР; текстовые панели редактирования |
| Составной документ | `--layout-document-width` | 4xl · 56rem · 896px | CV и перфоманс; две колонки полноэкранного редактора желания |
| Коллекция / отчёт | `--layout-collection-width` | 5xl · 64rem · 1024px | Wishlist, каталог, публичная коллекция, группы, ценности, Gallup, Hogan, образование, здоровье; сложный редактор перфоманса |
| Широкая | `--layout-wide-width` | 7xl · 80rem · 1280px | Сетка контактов, общая оболочка и глобальная навигация |

## Поведение

- Любой размер — верхний предел, а не фиксированная ширина. На телефоне содержимое занимает доступную ширину между полями по 16px; на промежуточных экранах поля равны 24px, на десктопе — 32px.
- Общая страница: 1280px содержимого + два поля по 32px = 1344px. Страница Wishlist: 1024px + два поля по 32px = 1088px. Шапка, профиль и карусель учитывают внешнюю рамку оболочки отдельно.
- Вкладка пропускает ширину дочернего содержимого целиком. Устранено дополнительное ограничение 940px, из-за которого коллекции с max-w-5xl не достигали 1024px.
- Каталог, личные и публичные списки, группы используют одну сетку: четыре колонки от 1024px, три от 641px, две до 640px включительно. Изображения сохраняют свои пропорции.
- Полноэкранный редактор желания: 896px, две колонки с промежутком 24px; до 820px — одна колонка максимум 576px. Боковые поля прокрутки — по 16px. Закрытие и Footer остаются вне прокрутки.
- Для боковых панелей используются `app-drawer--compact`, `app-drawer--form`, `app-drawer--document`, `app-drawer--wide`. На десктопе размер ограничен также шириной окна минус 32px. Нижняя мобильная панель занимает всю ширину. Внутренние Header/Content/Footer и высоты остаются в контракте shadcn Drawer.
- Меню действий: 288px; меню с дополнительными полями: 320px. Обе роли ограничены доступной шириной портала. Select и меню, привязанные к полю, продолжают использовать геометрию якоря Base UI.
- Обычные Dialog/AlertDialog сохраняют официальный Base Nova максимум 384px на десктопе и ограничение окном на телефоне. Размеры кнопок, полей, аватаров, иконок и обрезка подписей — отдельные роли, их нельзя подменять шириной страницы.

## Что устранено

Разрозненные размеры основных контейнеров 430, 760, 834, 860, 940, 980 и 1120px заменены общими ролями. Объединены 24 ограничения вложенных текстовых блоков. Боковые панели больше не теряют заданную ширину из-за приоритета классов примитива. У друзей исправлено смещение влево на планшете. У редактора желания исправлена фактическая одноколоночная компоновка на десктопе.

Проверки размеров доступны в `scripts/container-checks.mjs`; их нужно выполнять в уже авторизованном браузере. Проверка исходников запрещает возврат индивидуальных `--drawer-content-width` в JSX. `npm run test:ui`, шесть целевых тестов и `npm run build` проходят. В сборке остаётся прежнее предупреждение о размере JS-бандла.

Использована настроенная production-база. Формы не сохранялись, данные не создавались и не удалялись. Широкая панель перфоманса назначена по структуре формы и проверена в исходниках; открыть её через интерфейс не удалось, поскольку у текущего пользователя нет циклов ревью и кнопка редактирования отключена.
