# Доступность брендов каталога

Среди импортированных витрин Wishlist доступна прямая ссылка на BORK (`bork.ru`).
Единственный источник списка доступности — `shared/catalog-brands.js`.
Сервер ограничивает им список брендов и доступные страницы витрин; старые ссылки
на остальные витрины возвращают404. Импортёр использует тот же список.
Названия, логотипы и товары читаются из production PostgreSQL.

API внешних рекомендаций сохраняется для существующих клиентов. Страница
«Бренды» без параметра `brand` открывает каталог аккаунтов продавцов. Исходные
снимки других брендов и пользовательские желания сохраняются.

Импортированная витрина показывает подарочные сертификаты отдельным блоком над товарами, когда они есть в выбранном пространстве. Клиент запрашивает этот блок через `sections=certificates`; без параметра API сохраняет прежнюю выдачу.
