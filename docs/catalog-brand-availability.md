# Доступность брендов каталога

В каталоге брендов Wishlist опубликован только BORK (`bork.ru`).
Единственный источник списка доступности — `shared/catalog-brands.js`.
Сервер ограничивает им список брендов и доступные страницы витрин; старые ссылки
на остальные витрины возвращают404. Импортёр использует тот же список.
Названия, логотипы и товары читаются из production PostgreSQL.

Рекомендации остаются отдельным режимом каталога. Исходные снимки других брендов
и пользовательские желания не удаляются при изменении доступности витрин.
