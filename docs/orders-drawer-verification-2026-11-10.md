# Проверка шторы заказов 10 ноября 2026

Базовый коммит `f55cce47e5718bc411f39cfc9436930deb152f23`. В начале рабочая копия была чистой. Проверялись незакоммиченные изменения на Node.js 22.22.3.

## Что изменилось

- Кнопка «Заказы» открывает штору поверх магазина. При закрытии сохраняются позиция магазина и фокус на кнопке. Прямая ссылка `/app/orders` открывает ту же штору.
- Список прокручивается под шапкой. В карточках доставка и действие возврата занимают всю ширину отдельными строками. На 320 px помещаются сокращённый номер заказа, значок и цена.
- Escape в подтверждении возврата закрывает подтверждение и возвращает фокус на действие заказа. Повторное открытие списка запрашивает актуальные заказы.

## Результаты

- `npm run test:orders` прошёл на 320×568, 390×844, 390×400, 768×900, 820×900, 1024×768, 1440×900 и 1920×1080. Проверены размеры кнопок, геометрия шторы и карточек, длинный список, Back/Forward, прямая ссылка, фокус, загрузка, пустой список, повтор после ошибки и отмена возврата. Тест блокирует сетевые запросы к API. Просмотрены скриншоты 320×568, 390×400 и 1440×900.
- `npm run test:ui`, `npm run build` и `git diff --check` прошли. Сборка сообщает о крупном JS-чанке.
- `npm run check:comprehensive` остановился на 90-секундном тайм-ауте навигации в To Do в `test:controls` на 390×844. До него прошли unit-тесты (789 успешно, один пропущен) и аудит UI. Последующие этапы этого прогона не запускались.
- Отдельный повтор `npm run test:controls` прошёл полностью, включая 143 сочетания маршрута и размера, а также мобильные проверки при DPR 3.
- `npm run test:drawers` прошёл полностью на десяти размерах. Успешно завершены 40 проверок общих композиций и 230 проверок реальных форм.
- `npm run dev:keepalive:status` в основной рабочей копии подтвердил готовность постоянного сервиса. В браузере с локальным фронтендом этой рабочей копии и действующим production-backed API проверены доступность сервера, требование входа для API заказов и сохранение `next=/app/orders` при переходе на вход. Сервис оставлен работающим.
