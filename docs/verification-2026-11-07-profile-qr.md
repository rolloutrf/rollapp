# Проверка визитки в настройках профиля, 7 ноября 2026

База рабочей ветки `codex/remove-wishlist-business-plus` —
`9f9aa67768e22bddda3d9364f7a5016e55ccf4f2`. В начале в дереве были
изменения предыдущей задачи по шапке Вишлиста. Проверки выполнялись
с обоими изменениями.

Пункт «Визитка и QR-код» открывает общий компонент визитки из настроек
профиля. На телефоне используется нативный экран с возвратом в меню, на
компьютере — раздел внутри панели профиля.

- `npm run test:contacts` прошёл на девяти размерах от 320 до 1920 px.
  Проверены QR, браузерный и экранный возврат, восстановление фокуса,
  прокрутка, кнопки 48 px, скачивание vCard и JSON, копирование, отмена
  системного обмена и публичная визитка. Снимки меню и визитки на мобильном
  и настольном экранах просмотрены.
- `npm run test:contact-cards` прошёл на девяти размерах. Сценарии подписи
  используют синтетический транспорт кошелька.
- `npm run test:ui`, `npm run build` и `git diff --check` прошли.
  Vite выдал предупреждение о размере чанков.
- В превью с настроенным production PostgreSQL проверены публичная
  визитка, адрес профиля в карточке, локальная генерация QR и возврат
  фокуса при 390 и 1440 px. HTTP-записи блокировались. Авторизованный
  экран проверялся на тестовом профиле без сетевого API. Реальное
  сканирование телефоном и подпись живым кошельком не проверялись.
- Первый прогон `test:profile`, `test:profile-wishlists` и
  `test:controls` остановился на записи снимков из-за заполнения диска.
  После удаления временных кэшей `test:profile` и `test:profile-wishlists`
  прошли каждый на девяти размерах, включая короткие окна. Повтор
  `test:controls` и отдельный прогон `test:form-actions` завершили
  свои матрицы, включая проверку нативного Enter и Back.
- Общий `check:comprehensive`, запущенный до переноса QR, остановлен
  на `test:snippets` с кодом 143 при нехватке места. Его отчёт
  `/tmp/rollapp-remove-wishlist-business-plus-comprehensive.json`
  не является результатом полной проверки.
