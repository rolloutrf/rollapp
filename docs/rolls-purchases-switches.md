# Переключатели покупки роллов

Покупки за Telegram Stars и TON временно отключены по запросу владельца.
Код, цены, адрес получателя, история и обработчики платежей сохранены.

В `deploy/docker-compose.template.yml` флаги выставлены в `"false"`:

- `TELEGRAM_STARS_ENABLED`: создание новых счетов и разрешение Telegram checkout.
- `TON_ROLLS_ENABLED`: создание новых счетов TON и показ формы оплаты.
- `TON_WALLET_ENABLED`: показ карточки TON-кошелька вместе с балансом и подключением.

Кнопка «Пополнить баланс» и экран пополнения скрываются, когда
`TELEGRAM_STARS_ENABLED=false`. Интерфейс получает доступность функций из
`GET /api/rolls`; до загрузки настроек эти элементы также скрыты.
Для возврата TON-покупок нужны оба флага TON со значением `"true"`.

Для повторного включения нужного способа установить его флаг в `"true"`
и опубликовать обновление обычным production workflow. Перед включением
проверить актуальные условия приёма платежей и настройки получателя/курса.
Для локальной версии те же флаги задаются в `.env.local`; после изменения
перезапустить `npm run dev:stop` и `npm run dev:bg`.

`TON_ROLLS_WORKER_ENABLED` на production остаётся `"true"`: ранее отправленные
платежи должны продолжать проверяться. Локально worker остаётся выключенным.
Telegram `successful_payment` продолжает обрабатываться даже при отключённых
покупках; новые `pre_checkout_query` отклоняются сервером. Внешний Telegram
worker останавливать не нужно — решение о разрешении оплаты принимает backend.

Отключение формы TON не отменяет транзакцию, уже переданную в кошелёк, и не
отзывает ранее выданный счёт из блокчейна. Проверка и история таких платежей
сохраняются. Карточка TON скрыта без удаления её кода или сохранённой сессии.
Баланс роллов, история и переводы роллов остаются доступны.
