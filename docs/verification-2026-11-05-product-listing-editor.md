# Проверка добавления товара · 2026-11-05

Рабочая ветка `codex/product-listing-editor`, база
`bcc23d4e11c6691bfd655d3bad43c9d5748ad560` (`origin/main` на момент начала).
Исходный чистый worktree был на `f55cce4`, где редактора со скриншота ещё не
было. Проверялось дерево с незакоммиченными изменениями этой задачи.

## Форма

- Одна обложка в существующем поле `image_url`. Форматы JPG, PNG, WebP
  до 8 МБ. Замена, удаление и предпросмотр работают локально до сохранения.
- Форма показывает фактическую видимость по сохранённому состоянию витрины.
  Название и ссылка проверяются до загрузки. Данные остаются после сбоя, а
  повтор создания с тем же `requestId` возвращает ту же карточку. Список
  обновляется из ответа сервера и сохраняет несохранённые настройки витрины.
- Исправлены тесные отступы зоны загрузки на десктопе и лишняя запись в истории
  при переходе из деталей в редактор на телефоне. Переключение ждёт закрытия
  исходной формы через общий `onAfterClose`. Ассерт подсветки drop-зоны ждёт
  отрисовки React.
