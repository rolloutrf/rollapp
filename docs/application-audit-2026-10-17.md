## Найдено и исправлено

1. **Прозрачность закреплённых действий.** У Back тёмный вариант Base Nova возвращал полупрозрачный `bg-input/30`; disabled Save наследовала `opacity: .5`, а hover Delete — фон с alpha .5, поэтому сквозь кнопки просвечивали поля. В общем product-слое заданы сплошные outline/select/neutral-icon surfaces, непрозрачные состояния наведения Back/Save/Delete и отдельные muted-цвета disabled при полной opacity. Размеры остаются 48 px, исходные shadcn-примитивы сохранены. Регрессия проверяет opacity, alpha фона, пустую/заполненную задачу, hover, скролл и клавиатуру.
2. **Отступы страницы входа.** Отрицательные margins ссылки «Забыли пароль?» нарушали общий gap формы: вместо 24 px получались 15/14 px. Убраны; 12 сочетаний auth-экранов и ширин повторно проверены.
3. **Небезопасные стандартные команды.** `npm test` вызывал общий discovery с legacy memory-интеграциями. Теперь он запускает только `test:unit`, а `npm run check` — безопасный `check:release`. Обязательный UI audit проверяет эти алиасы.
4. **DDL в production-проверке recurrence.** Убрана инициализация схемы с DROP/ADD CONSTRAINT. Проверяется наличие существующих колонок; временные записи откатываются. Добавлены ограничители выполнения/ожидания блокировок. Оба production planning-теста прошли.
5. **Зависимости.** Начальный npm audit: 22 замечания (3 critical, 14 high, 5 moderate). Установлены совместимые исправления, включая compression 1.8.2, proxy-addr 2.0.8, undici 7.30.1, concurrently 9.2.5 и sharp 0.35.5. CLI shadcn 4.22.0 вынесен в devDependencies. Итоговый runtime audit — 0; полный audit — 7 high в одной dev-цепочке braces → micromatch/fast-glob → shadcn/registry/ts-morph. Несовместимый downgrade shadcn до 1.0.0 не применяется.
6. **Выпуск.** Ограничены время и повторы скачивания YC CLI. Убран автоматический restart здоровой старой версии при задержке согласования образа: до restart требуется диагностика диска и pull. Проверено 12 GB свободного места из 19 GB, работающий контейнер и корректная production health-версия. Автоматическая очистка образов/volumes и изменения БД не выполнялись.
7. **Воспроизводимость аудита.** Добавлен `check:comprehensive`: последовательный полный набор, отказ от унаследованных частичных фильтров, fail-fast, JSON со статусами этапов, SHA и dirty-флагом. Расширенные UI-сценарии используют общий поиск Chrome на macOS/Linux и `CHROME_PATH`.
8. **Зависимость To Do smoke от дня запуска.** На 17 октября сценарий начал сравнивать сохранённую дату с пустым параметром URL, который штатно сокращает «сегодня». Зафиксировано время браузера без остановки таймеров; отдельно добавлен и пройден случай «сегодня без date в URL». Дата задачи сохраняется корректно в обоих вариантах.
9. **Анимация возврата к исходному документу.** Новая покадровая регрессия обнаружила, что после закрытия формы глобальный smooth scroll заставляет страницу ехать от 0 к сохранённой позиции (вместо мгновенного восстановления). Для входа/возврата задан `behavior: "instant"`; проверяются первые кадры и стабильность обеих кнопок Back на глубоко прокрученном документе.

## Ограничения и остаточные вопросы

- 7 high npm warnings остаются только в инструментарии shadcn; уязвимая цепочка не входит в `npm ci --omit=dev`. До совместимого upstream fix не передавать генератору недоверенные glob-шаблоны. Это не основание отключать shadcn-аудит или ломать совместимость компонентов.
- Сборка сохраняет предупреждение о крупном основном JS chunk (около 1.7 MB до gzip). Code splitting требует отдельной проверки поведения маршрутов; предупреждение не скрывалось повышением лимита.
- Unit-набор намеренно пропускает opt-in production TON settlement. Платежи, рассылки, административные роли, реальные загрузки файлов, все комбинации прав и сохранение пользовательских записей не выполнялись.
- Chrome/VisualViewport fixtures проверяют геометрию клавиатуры и panning. Физические iOS Safari/Telegram WebView и экранная клавиатура на устройстве в этот прогон не входят.
- При закрытии action-rail Chrome на macOS orphan crash handlers удерживали stderr после всех успешных сценариев. Три helper сопоставлены с точным peer socket теста и освобождены; сценарий завершился штатно. В общий launcher расширенных сценариев добавлены документированные test-only crashpad/updater switches: отдельная 25-секундная проверка завершила Chrome за 45 ms. Пользовательский браузер и dev-сервис не завершались. Порядок диагностики записан в регламенте.
- Широкий UI проход не гарантирует отсутствие любых ошибок: отчёт фиксирует проверенные поверхности и состояния. Старые mutating/memory-сценарии не запускались; их замена не подменяется зелёным build.
