# Сторис

`StoryAvatar` доступен только на маршрутах раздела «Друзья»: `/app/friends` и его вложенных страницах. Своя аватарка без активных сторис открывает запись; с активными — просмотр с действием «Добавить сторис». На остальных страницах своя аватарка открывает обычный редактор профиля. Публичный профиль не предоставляет вход в сторис. MobileFormPages охватывает также ProfileEditorProvider, а переход к настройкам из сторис выполняется через onAfterClose после восстановления истории.

Запись начинается после явного нажатия «Записать» и разрешения камеры/микрофона. MediaRecorder останавливается через 60 секунд; ручная остановка доступна раньше. Камера освобождается при остановке, закрытии, уходе со страницы, скрытии документа и размонтировании. Поздний ответ getUserMedia не может возобновить закрытую запись. Системная камера/выбор видео остаются доступны в браузерах без MediaRecorder. Файл ограничен 25 МБ. Публикация требует отдельного нажатия после предпросмотра; ошибка сохраняет запись для повтора. Закрытие до нажатия «Опубликовать» ничего не публикует. Уже подтверждённая публикация может завершиться после закрытия экрана.

Сервер принимает авторизованные загрузки, ограничивает частоту по пользователю и выполняет только одну перекодировку одновременно на процесс. FFmpeg декодирует вход, обрезает первые 60 секунд и перекодирует в MP4 H.264/AAC с максимальной рамкой 720×1280. FFprobe проверяет фактическую длительность результата, независимо от клиентских метаданных. Установленный FFmpeg/FFprobe требуется для сервера и unit-проверки реальной обрезки; Docker и CI устанавливают его явно. Временные файлы удаляются при любом исходе.

Опубликованные сторис публично доступны через media API; вход в интерфейс сторис находится только в разделе «Друзья». У каждой публикации свой срок: ровно 24 часа от серверного created_at. И список, и прямой URL видео проверяют expires_at на стороне PostgreSQL; ответы имеют Cache-Control: no-store. Видео поддерживает byte ranges для мобильного воспроизведения. Клиент обновляет список при публикации, возврате фокуса и раз в минуту; локальное истечение срока проверяется ежесекундно. Оранжевое кольцо (`--story-ring` в index.css) видно, пока остаётся хотя бы одна активная публикация. Уже загруженную копию видео отозвать невозможно. Истёкшие записи не выдаются через API; физическая очистка хранилища не запускается автоматически и требует отдельной согласованной политики.

Мобильный экран использует MobileFormScreen/MobileFormFooter через form-surface: нативный Back отменяет запись, один document scroller, общие safe area/VisualViewport и 48px действия. Настольный вариант — правая штора с отдельным прокручиваемым телом. Иконки действий имеют 20px, кнопки в ControlBar — 48px и круглые/капсульные края. Имя профиля остаётся семантическим h1; вложенная кнопка настроек наследует именно его типографику. Семейство и глобальная шкала текста не меняются.

## Хранение и выпуск

`server/migrations/20261101-stories.sql` — отдельная операция, создающая таблицу stories и индекс по владельцу/сроку. Она не запускается автоматически при старте приложения. Startup verify проверяет столбцы в READ ONLY транзакции и сохраняет guard зарезервированных имён. Перед выпуском миграция должна быть отдельно явно разрешена и применена к точной настроенной базе.

1 ноября 2026 пользователь явно разрешил создание таблицы stories; миграция применена к настроенной production-базе через проверенный TLS. Существующие данные не менялись.

## Проверки

`npm test` включает проверки маршрутов, сроков и ranges без БД и реальную FFmpeg-проверку обрезки 61-секундного видео.

`npm run test:stories` — восемь экранов 320/390/768/820/1024/1440/1920 и 390×400 в светлой и тёмной темах: камера Chromium, остановка, освобождение stream, предпросмотр, ошибка/повтор публикации, кольцо, реальное декодирование MP4 в просмотре, запрет авторинга для гостя, геометрия и закрытие. Дополнительно проверяет deadline виртуальными часами браузера, отказ камеры и поздний ответ getUserMedia после отмены. Presentation hook/transport подменены явно внутри fixture; запросы API запрещены. Проверка входит в check:release и check:comprehensive. Снимки: /tmp/rollapp-stories.

Эмуляция Chromium не заменяет проверку записи/разрешений камеры на настоящем iPhone, Safari, Android и Telegram WebView. Production QA не публикует тестовые сторис.

Проверка маршрутов в `test:stories` использует реальный PersistentProfileHero: `/app/friends`, `/app/friends/`, подписки и подписчики открывают сторис, а Wishlist, сфера и похожий префикс `/app/friendship` открывают профиль. Семь размеров экрана, 49 переходов; публичный профиль сохраняет прежнюю композицию без StoryAvatar.
