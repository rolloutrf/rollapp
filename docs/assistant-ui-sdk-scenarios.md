# Сценарии UI SDK в Роллаппе

Оценка по текущим маршрутам, формам и действиям ассистента на 13 ноября 2026 года. Приоритет 1 означает ближайший прототип, 2 — развитие после первого прототипа, 3 — точечное применение. Приоритет учитывает количество ручных шагов, готовность данных и возможность проверить предложенные изменения на одном экране. Это оценка по устройству приложения, без замеров частоты действий пользователей.

Сейчас модель может предложить открыть вишлист, To Do, календарь, Kanban, заметки и доступные пользователю сферы. Она готовит отдельные редактируемые черновики желаний, задач, событий и заметок. Для совета по планированию доступно до 30 незавершённых задач и событий на семь дней. Штатные формы выполняют сохранение. [Контракт ассистента](messenger.md)

| Раздел и сценарий | Приоритет | Роль UI SDK и необходимые изменения |
| --- | --- | --- |
| Вишлист — добавить желание | Работает | Карточка через SDK открывает штатную форму с названием, ценой и списком. Пресет «Добавить желание» воспроизводит сценарий. |
| Вишлист — разобрать «Не отсортированные» | Работает | Панель показывает до 10 предложений. Пользователь меняет списки и выбирает строки. Перед переносом сервер проверяет принадлежность и актуальность всего набора. |

Снимка до 30 записей для поиска времени недостаточно. |

Для переноса сначала выбрать конкретную доску и предложить изменения по карточкам. SDK позволяет менять колонку в предварительном просмотре, включая клавиатурное управление без перетаскивания. |

| Образование — курсы, конференции, коучинг | 2 | По выбранной записи предложить план обучения, задачу или событие. Подходящие контролы — выбор курса, темы, даты и списка To Do. |
| Карьера — ИПР, CV, перфоманс | 2 | По выбранному фрагменту ИПР предложить действия и контрольные точки. SDK управляет выбором пунктов и формами планирования. Правки CV и перфоманса проверяются в их редакторах. |

| Покупки, заказы, магазин и объявления | 2–3 | Наиболее полезны фильтр заказов, предпросмотр импорта покупок и черновик объявления. SDK даёт выбрать записи для импорта и заполнить форму. Оплата и публикация остаются действиями в соответствующих экранах. |
| Роллы, профиль, настройки и доступы | 3 | SDK может открыть нужный экран и помочь прочитать статус. Простые переходы удобнее отдать существующим ссылкам. Для операций с балансом и правами используются штатные подтверждения Роллаппа. |
| Совместные желания, подарки, сборы | 3 | Полезны поиск подходящего желания и предварительный просмотр участников, суммы и условий. Бронь, приглашения и взносы выполняются на своих экранах с учётом роли и видимости. |
| Редакторы документов и таблиц | 3 | SDK может предложить операцию для выделенного блока, например превратить текст в список. Сохранение выделения, структура таблиц и Undo должны оставаться у редактора. Начинать стоит с одной команды, у которой есть очевидный предпросмотр. |

## Пресеты чата

В пустом чате и в меню девять общих пресетов. Ещё восемь появляются у аккаунтов с доступом к сферам. Поверх открытой заметки доступен отдельный пресет разбора на задачи. Пресет подставляет запрос в поле ввода. Там можно заменить пример своими данными или добавить исходный текст. После отправки чат показывает до трёх черновиков со штатными формами или одну панель разбора желаний.

| Где | Пресет и результат | Какие действия экономит |
| --- | --- | --- |
| Вишлист | «Добавить товар по ссылке» заполняет ссылку и указанный список. Форма подтягивает доступные данные товара. «Добавить несколько желаний» даёт до трёх карточек. | Ввод ссылки, названия, цены и списка. Для нескольких товаров достаточно одного сообщения. |
| Планирование | «Встреча и подготовка» даёт событие с повесткой и отдельную задачу. «Разбить цель на задачи» даёт до трёх карточек с результатами и сроками. | Ручное переключение между календарём и To Do, ввод времени, длительности и описания для каждого пункта. |
| Заметки | «Заметка и задачи из диктовки» готовит заметку с решениями и до двух задач из присланного текста. | Разбор сырой записи, повторный перенос формулировок и сроков в To Do. |
| Идентичность | «Ценности и действия на неделю» готовит заметку и до двух задач из примеров пользователя. «Уточнить ответ из “4 вопросов”» даёт новую версию в черновике заметки. | Сведение примеров в один документ, формулировка следующих шагов и создание задач. |
| Здоровье | «Поставить тренировки в календарь» готовит два события. «Собрать наблюдения и вопросы к приёму» структурирует присланные записи в заметку. | Повторный ввод даты, времени, длительности и описания. Сбор хронологии и вопросов в одном месте. |
| Образование | «Разложить курс по календарю» готовит три занятия с целями. «Выводы и задачи после обучения» даёт заметку и до двух практических задач. | Повторное создание учебных блоков, перенос выводов в план. |
| Карьера | «Собрать материалы к ревью» готовит заметку с достижениями и задачи на сбор подтверждений. «Превратить пункт ИПР в задачи» даёт задачи и контрольную встречу. | Структурирование материала, создание отдельных задач и заполнение события. |

Для разбора личных документов пользователь добавляет нужный фрагмент в чат. Работа прямо с выделением и запись в документ относятся к следующему этапу. Пресеты используют штатные формы с отдельным сохранением каждой карточки.

| Что проверять в первую очередь | Почему | Как понять, что пресет помогает |
| --- | --- | --- |
| Товар по ссылке | Источник уже содержит часть полей. Назначение списка и явно указанная цена приходят из того же сообщения. | Доля карточек, для которых достаточно проверить поля и сохранить. Какие поля приходится исправлять. |
| Итоги встречи или обучения → заметка и задачи | Один исходный текст обычно содержит и решения, и следующие шаги. Он годится для трёх черновиков. | Время от исходного текста до готовых черновиков. Какие задачи пользователь выбрал, исправил или отбросил. |
| Цель или ИПР → задачи и контрольная дата | У каждого шага есть отдельный результат. Его можно проверить до записи в план. | Сколько предложенных действий конкретны, имеют правильный срок и попадают в To Do после проверки. |
| Тренировки и учебные блоки → календарь | Дата, время и длительность повторяются. Запрос заполняет их для нескольких событий сразу. | Число корректно заполненных блоков. Число ручных исправлений расписания. |

Примитив пресетов UI SDK регистрирует действие `insertPreset`. Оно принимает ключ из локального каталога и вставляет соответствующий текст в активный черновик. Состояние проверяет доступность ввода и лимит сообщения. Меню использует общие компоненты Роллаппа для фокуса и клавиатуры. [Репозиторий Vercel UI SDK](https://github.com/vercel-labs/ui)

«Разобрать „Не отсортированные“» готовит одну панель для проверки до десяти товаров. В ней можно поменять списки и снять отметки, затем перенести выбранное одной операцией. Сценарий можно оценить по доле принятых предложений, количеству исправленных назначений и времени от запроса до переноса. Тот же способ проверки нескольких предложений можно применить к задачам из заметки и плану на неделю.

| Следующий пресет | Текст запроса | Что проверяем в прототипе |
| --- | --- | --- |
| Найти товар по бюджету | «Покажи мои кофемолки до 5 000 ₽. Отсортируй от дешёвых к дорогим». | Видны источник, бюджет и сортировка. Изменение фильтра обновляет тот же список. |
| Найти время для встречи | «Найди три свободных интервала по 45 минут в будни на следующей неделе с 10:00 до 18:00». | Видны календарь и часовой пояс. Выбранный интервал попадает в форму с исходной длительностью. |
| Сделать задачи из заметки | «Предложи задачи из выбранной заметки. Если в тексте нет срока, оставь дату пустой». | Каждый пункт редактируется отдельно. Можно сохранить только выбранные задачи. |
