# Сценарии UI SDK в Роллаппе

Оценка по текущим маршрутам, формам и действиям ассистента на 13 ноября 2026 года. Приоритет 1 означает ближайший прототип, 2 — развитие после первого прототипа, 3 — точечное применение. Приоритет учитывает количество ручных шагов, готовность данных и возможность проверить предложенные изменения на одном экране. Это оценка по устройству приложения, без замеров частоты действий пользователей.

Сейчас модель может предложить открыть вишлист, To Do, календарь, Kanban, заметки и доступные пользователю сферы. Она готовит отдельные редактируемые черновики желаний, задач, событий и заметок. Для совета по планированию доступно до 30 незавершённых задач и событий на семь дней. Штатные формы выполняют сохранение. [Контракт ассистента](messenger.md)

| Раздел и сценарий | Приоритет | Роль UI SDK и необходимые изменения |
| --- | --- | --- |
| Вишлист — добавить желание | Работает | Карточка через SDK открывает штатную форму с названием, ценой и списком. Пресет «Добавить желание» воспроизводит сценарий. |
| Вишлист — разобрать «Не отсортированные» | 1 | Панель показывает до 10 предложений. Агент может выставить предложенный список для строки, пользователь меняет назначение и выбирает строки. Нужны выборка доступных желаний и списков, повторная проверка принадлежности и состояния перед переносом, результат по каждой строке. |
| Вишлист и каталог — найти, отфильтровать, сравнить | 1 | По запросу «Покажи кофемолки до 5 000 ₽» SDK выставляет видимые фильтры и открывает результаты. Можно менять бюджет и открывать карточку. Нужен поиск по нужному источнику, с ценой из данных Rollapp или каталога. |
| To Do — подготовить задачу | Работает | Запрос из пресета предлагает открыть существующую форму задачи. SDK пригодится при выборе списка, даты и нескольких задач в одной панели. |

Поиск времени требует полной выборки занятости на заданный период с часовым поясом и повторениями. SDK выбирает один из рассчитанных интервалов и заполняет форму. Снимка до 30 записей для поиска времени недостаточно. |
| Заметки — подготовить заметку, получить задачи из заметки | Частично работает / 1 | Пресет готовит отдельную заметку. Для задач нужен явный выбор исходной заметки или выделенного текста и редактируемый список предложений. После проверки пользователь добавляет выбранные пункты в To Do. |
| План на неделю | Работает / 2 | Пресет даёт текстовый совет по доступному снимку. Следующий шаг — панель с приоритетами, датами и отдельным выбором задач, расписание которых пользователь хочет изменить. |
| Kanban — открыть доску, разложить карточки по колонкам | Частично работает / 2 | Запрос из пресета предлагает перейти на доску. Для переноса сначала выбрать конкретную доску и предложить изменения по карточкам. SDK позволяет менять колонку в предварительном просмотре, включая клавиатурное управление без перетаскивания. |
| Друзья, контакты и сообщения | 2 | Поиск по уже доступным контактам, выбор совпадения и черновик сообщения или встречи. Нужен выбор получателя при совпадении имён. Отправка остаётся кнопкой мессенджера. |
| Образование — курсы, конференции, коучинг | 2 | По выбранной записи предложить план обучения, задачу или событие. Подходящие контролы — выбор курса, темы, даты и списка To Do. |
| Карьера — ИПР, CV, перфоманс | 2 | По выбранному фрагменту ИПР предложить действия и контрольные точки. SDK управляет выбором пунктов и формами планирования. Правки CV и перфоманса проверяются в их редакторах. |
| Идентичность — документы и тесты | 3 | Открытие раздела уже предусмотрено для доступной сферы. SDK полезен для выбора раздела, навигации по отчёту и точечных предложений к выделенному тексту. Для короткого перехода достаточно ссылки. |
| Здоровье — тренировки, сон, питание, препараты, анализы | 3 | Полезны переход к экрану, выбор даты и заполнение дневника данными пользователя. Для анализов и препаратов наибольшая польза от поиска и навигации по уже существующим записям. |
| Покупки, заказы, магазин и объявления | 2–3 | Наиболее полезны фильтр заказов, предпросмотр импорта покупок и черновик объявления. SDK даёт выбрать записи для импорта и заполнить форму. Оплата и публикация остаются действиями в соответствующих экранах. |
| Роллы, профиль, настройки и доступы | 3 | SDK может открыть нужный экран и помочь прочитать статус. Простые переходы удобнее отдать существующим ссылкам. Для операций с балансом и правами используются штатные подтверждения Роллаппа. |
| Совместные желания, подарки, сборы | 3 | Полезны поиск подходящего желания и предварительный просмотр участников, суммы и условий. Бронь, приглашения и взносы выполняются на своих экранах с учётом роли и видимости. |
| Редакторы документов и таблиц | 3 | SDK может предложить операцию для выделенного блока, например превратить текст в список. Сохранение выделения, структура таблиц и Undo должны оставаться у редактора. Начинать стоит с одной команды, у которой есть очевидный предпросмотр. |

## Пресеты чата

В меню чата восемь общих пресетов и 28 пресетов сфер для аккаунтов с доступом. Каждый пресет навигации формирует запрос на конкретную вкладку. Выбор возвращает фокус в поле ввода. При наличии черновика текст добавляется отдельным абзацем. Отправка выполняется кнопкой чата или клавиатурной командой. На странице сферы пустой чат предлагает сценарий для неё и переходы к вкладкам.

| Сфера | Вкладки, доступные через чат | Готовый сценарий | Следующее применение UI SDK |
| --- | --- | --- | --- |
| Идентичность | 4 вопроса, Ценности, Характер, Тесты, Миссия, Идеальное состояние, Жизненная стратегия, Персональный План Развития, Тезисы, Принципы | Подготовить заметку с вопросами о ценностях | Выбрать один ответ из «4 вопросов» или фрагмент стратегии, показать предлагаемую правку и применить её через редактор с Undo. В тестах дать выбрать отчёт и перейти к нужной шкале. |
| Здоровье | Анализы, Спорт, Препараты, Сон, Питание | Подготовить событие «Тренировка» с датой, временем и длительностью | Заполнять дневники сна и питания по введённым фактам, открывать выбранную тренировку. Для анализов и препаратов начать с фильтра и перехода к записи. |
| Образование | Курсы, Конференции, Коучинг | Подготовить событие «Занятие по курсу» | Из выбранного курса, конференции или сессии коучинга подготовить план с задачами и событиями. В панели проверки менять даты и выбирать, какие пункты добавить. |
| Карьера | О себе, Домен, CV, Перфоманс, ИПР, Контакты | Подготовить заметку с вопросами к ревью | Из выбранного пункта ИПР предложить задачи и контрольные даты. Для CV и перфоманса показать правки к выбранному фрагменту, для контактов — показать совпадения и подготовить черновик встречи. |

Маршруты и названия вкладок берутся из общего каталога навигации. Ассистенту передаются только разрешённые ключи и названия. Примеры для сфер используют существующие черновики заметок и событий. Содержимое сферы доступно пользователю на её экране.

Примитив UI SDK регистрирует единственное действие `insertPreset`. Оно принимает ключ из локального каталога и вставляет соответствующий текст в активный черновик. Состояние проверяет доступность ввода и лимит сообщения. Меню использует общие компоненты Роллаппа для фокуса и клавиатуры. [Репозиторий Vercel UI SDK](https://github.com/vercel-labs/ui)

Первый следующий сценарий для прототипа — разбор «Не отсортированных». Его можно оценить по доле принятых предложений, количеству исправленных назначений и времени от запроса до завершения переноса. Затем тот же способ проверки нескольких предложений можно применить к задачам из заметки и плану на неделю.

| Следующий пресет | Текст запроса | Что проверяем в прототипе |
| --- | --- | --- |
| Разобрать желания | «Предложи, по каким из моих списков разложить первые 10 желаний из “Не отсортированных”. Покажи предложенные назначения». | Видны исходная карточка и целевой список. Можно исправить назначение и исключить карточку до переноса. |
| Найти товар по бюджету | «Покажи мои кофемолки до 5 000 ₽. Отсортируй от дешёвых к дорогим». | Видны источник, бюджет и сортировка. Изменение фильтра обновляет тот же список. |
| Найти время для встречи | «Найди три свободных интервала по 45 минут в будни на следующей неделе с 10:00 до 18:00». | Видны календарь и часовой пояс. Выбранный интервал попадает в форму с исходной длительностью. |
| Сделать задачи из заметки | «Предложи задачи из выбранной заметки. Если в тексте нет срока, оставь дату пустой». | Каждый пункт редактируется отдельно. Можно сохранить только выбранные задачи. |
