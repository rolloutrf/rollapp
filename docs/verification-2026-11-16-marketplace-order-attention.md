# Подборки действий по заказам, 2026-11-16

Рабочая ветка `codex/rollapp-finance-system-20261116`. Целевые команды
проверили `844e33e1` с незакоммиченными изменениями истории, кошелька и
браузерных проверок.

## Изменения

- Кошелёк показывает число покупок на приёмке, заказов к исполнению,
  открытых споров и доступных выплат. Для приёмки указан ближайший срок,
  для выплаты — сумма роллов. В ответе сводки только агрегаты текущего
  участника.
- «Заказы» открывают выбранную из кошелька подборку. Общий список
  сохраняет порядок. Сохранённая проверка доступна в исходной подборке
  после изменения статуса. После её завершения список обновляется. Если карточка исчезает, фокус переходит к списку.
- Общая SQL-проекция учитывает роли, состояние и время PostgreSQL.
  Проверка границы срока сравнивается с серверным временем.

Браузерные проверки блокировали обращения к реальному API. SQL-проверка
подборок использовала синтетические строки в READ ONLY запросе к
настроенной базе. Проверка не создавала таблиц, не меняла флагов и не
проводила реальные сделки. Полный прогон `44c3a4f2` относится к предыдущей
ревизии. Для текущих изменений требуется отдельный полный прогон.
