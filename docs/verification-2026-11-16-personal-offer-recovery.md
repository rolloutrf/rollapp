# Восстановление оплаты и возврата персонального счёта

16 ноября 2026, Москва. Базовый коммит `555feeb2`, ветка
`codex/rollapp-finance-system-20261116`. Проверялись изменения персональных
счетов. `git diff --check` прошёл.

Подтверждённое действие сохраняется отдельно для аккаунта, счёта и роли.
Покупатель проверяет оплату, продавец — возврат. Кошелёк показывает
незавершённое локальное действие независимо от страницы списка, а после
проверки сообщает результат, даже если нужный счёт отсутствует в списке.
Вишлист открывает ту же операцию из карточки товара. Результат проверяется
посредством GET с приватным кэшированием и транзакцией READ ONLY.
Пустая проверка позволяет повторить операцию вручную с исходной суммой.
При подтверждённом отказе в оплате можно заново подтвердить действие после
решения причины. Старые клиенты с пустым телом сохраняют совместимость.

Диагностика выявила, что маршрут списка Вишлиста не передавал идентификатор
активного аккаунта в карточку. Маршрут теперь берёт его из сессии. Тест
геометрии ждёт конца анимации окна, чтобы измерять кнопку при масштабе 1.
Полная матрица была запущена до добавления отдельного сообщения для счёта
вне списка. Финальный прогон восстановления проверяет это состояние.

Полный релизный прогон и публикация остаются открытыми. Схема и постоянные
данные рабочей PostgreSQL не изменялись.
