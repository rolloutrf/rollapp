# Сверка свежих и архивных платежей TON

16 ноября 2026, Москва. Базовый коммит `f0a10643`, ветка
`codex/rollapp-finance-system-20261116`. Проверки до коммита выполнены на
дереве с изменениями обработчика. `git diff --check` прошёл.

В прежнем обработчике курсор истории замещал чтение самых свежих транзакций.
Ошибка отдельного получателя, записи или начисления могла завершить весь
проход. Теперь каждая итерация читает свежие страницы всех получателей перед
архивом. Первая архивная запись определяется по логическому времени и хешу
предыдущей транзакции в проверенном BOC. Пустые и ошибочные страницы сохраняют
архивный курсор, а архив повторно проверяется после достижения границы
неоплаченных счетов. Некорректная запись или временный сбой начисления
отражаются в итогах прохода. Обработка других подтверждённых платежей
продолжается.

чистый полный прогон остаются открытыми. Результат полного прогона для
