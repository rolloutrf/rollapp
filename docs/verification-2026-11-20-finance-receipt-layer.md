# Квитанция в шторке «Финансы» — 20 ноября 2026

Проверено рабочее дерево `codex/business-offers-subscriptions-20261119`
поверх `0bbe7b7fc32ac4c3cb6dcae3640e0056242bcaf2` с ранее существовавшими
незакоммиченными правками.

В «Финансах» профиля на компьютере квитанция открывается в следующем слое
правой шторы. Журнал сохраняет прокрутку и загруженные строки. На время
просмотра панель журнала исключена из навигации и дерева доступности.
На телефоне квитанция использует вложенный экран с нижними действиями.
На отдельной странице кошелька действует полноэкранная композиция.

- `npm run test:purchase-history` прошёл на всех восьми размерах.
  Проверены совпадение границ правой шторы, фокус, прокрутка журнала,
  возврат кнопкой и историей браузера, повтор загрузки и скачивание TXT.
  Просмотрены кадры 390×844 и 1440×900.
- `npm run test:orders` и `npm run test:controls` прошли при подключении
  вложенной шторы. Итоговый вариант с изоляцией журнала прошёл
  `npm run test:purchase-history`, `npm run test:ui`, `npm run build`
  и `git diff --check`. Сборка сообщила о чанках свыше 500 кБ.
- `npm audit` сообщил о 7 проблемах умеренной и 2 высокой серьёзности.
  Повторный `npm audit --omit=dev` сообщил о двух проблемах высокой
  серьёзности в цепочке `@ton/ton` → `zod`. Зависимости не менялись.

Браузерные сценарии блокировали обращения к рабочему API. Сервис разработки
в основном рабочем дереве доступен. Авторизованная проверка на рабочем сайте
остаётся за пределами этого прогона. Правка в рабочей ветке.
