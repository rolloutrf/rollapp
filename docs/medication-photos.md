# Фото препаратов

`Medications` использует существующую `CollectionSnippetMedia`: упаковка целиком
помещается в карточку через object-fit: contain; изображение позиционируется
внутри рамки, чтобы его intrinsic-размер не увеличивал grid track; статус остаётся поверх медиа.
При смене URL сбрасывается fallback изображения. Старая запись без фото сохраняет
иконку препарата. Shared read-only показывает фото без формы изменения.

В `MedicationDrawer` доступны ссылка HTTP/HTTPS и JPG/PNG/WEBP до 8 МБ через
существующий authenticated `/api/uploads/images`. Предпросмотр имеет имя препарата.
Во время загрузки Save, закрытие и конкурирующие действия недоступны. Ошибка Save
оставляет черновик/фото для повторной попытки. Отмена не меняет сохранённую запись.
Поздний ответ загрузки после смены владельца формы не меняет следующий черновик.
Очистка касается только новых временных uploads этой формы; ранее сохранённые
файлы не удаляются. `/api/uploads/images/:id` проверяет owner-scoped ссылки
`health_medications.image_url` наряду с другими документами и fail-closed при
ошибке запроса. При сохранении `/api/media/:id` сервер проверяет владельца upload.

API возвращает `imageUrl` (пустая строка для старых записей). При PATCH без imageUrl
старый клиент сохраняет существующее фото; явная пустая строка убирает его.
Нельзя сохранять javascript/data/file/protocol-relative ссылки. Изменение группы
не теряет фото. Поля назначения, дозировки и периода независимы от фотографии.
Для запланированного курса custom может содержать пустой список времён: карточка
пишет «Схема не указана». У активной custom-схемы время по-прежнему обязательно.
Это позволяет сохранять покупку без придуманного назначения/расписания.

Хранилище: `health_medications.image_url TEXT NOT NULL DEFAULT ''`.
Отдельная additive миграция: `node scripts/migrate-medication-photo.mjs` только
проверяет production READ ONLY; `--apply` требует отдельного явного разрешения.
Она не делает UPDATE/backfill/cleanup. Обычный verify startup только выполняет
`SELECT id,user_id,image_url FROM health_medications LIMIT 0`.

`npm run test:medication-photos` использует настоящие форму/карточку и production
CSS на 320/390/768/820/1024/1440/1920px и коротких 390/1024×400px. Проверяет
ссылку/preview, cancel/retry/save/reopen/remove, запрет SVG, upload, защиту
сохранённого upload, поздний ответ после смены владельца и ControlBar48/radii.
Transport явно передан fixture, реальные API запрещены. Входит в check:release.
