# Наведение на ссылку «Друзья», 14 ноября 2026

База — `b5c099ce9661e78d47040dba88771b6decde92ac`. В рабочем дереве также
были изменения плавающих контролов и отчёта о бронировании.

Ссылка в профиле и Вишлисте использует вариант shadcn `link`. При
наведении меняется цвет текста и иконки. Фон, граница и тень остаются
прозрачными, а при клавиатурном фокусе появляется штатное кольцо.

- `npm run test:profile-wishlists`, `npm run test:ui` и `git diff --check`
  прошли.
- Chromium подтвердил высоту 48 px, прозрачный hover и видимый
  `:focus-visible` в обеих темах для собственного публичного профиля и
  личного Вишлиста. Проверены 320, 390, 768, 820, 1024, 1440 и 1920 px,
  в том числе высота 400 px. Запросы к API запрещены в fixture.
- Локальный preview с production PostgreSQL готов. Авторизованный
  production-сеанс и отдельный выпуск не проверялись.
