# Источники импорта вишлистов

Правка проверена в отдельном рабочем дереве с изменениями поверх `42a4402d`.

- Шапки личного Вишлиста и публичного профиля обходятся без блока со ссылками на внешние вишлисты. Сохранённые ссылки доступны в настройках импорта. В деталях товара убраны подписи «Исходная ссылка» и «Сохранённая карточка». Ссылки на предложения и бейдж «Лучшее» доступны.
- `npm run test:profile-wishlists` прошёл на девяти размерах. Проверены отсутствие ссылок в обеих шапках, появление импортированных карточек без бейджей, сохранение ссылок в настройках, повтор импорта и обработка ошибок.
- `npm run test:details` прошёл на восьми размерах. Браузер проверил товар с сохранённым предложением до и после поиска, доступность ссылки, отсутствие подписей происхождения и сохранение бейджа «Лучшее» у найденного предложения.
- `npm run test:catalog-page` и `npm run test:offers` прошли полные матрицы.
- `npm run test:ui`, `npm run build` и `git diff --check` прошли. Unit-этап `npm run check:comprehensive` завершился с 1006 успешными тестами и одним пропуском.
- Локальный кандидат запущен с настроенной production PostgreSQL в режиме `verify`. На 390×844 и 1440×900 гостевой профиль с реальной сохранённой ссылкой показал карточки без блока источников. Проверка выполнила только чтение. Авторизованный интерфейс с реальными данными не проверялся.
- `npm audit` сообщил 8 замечаний, `npm audit --omit=dev` сообщил 2. Версии зависимостей соответствуют базовому коммиту.

Полный прогон `check:comprehensive` запущен. Результат прогона и выкладка на публичный сайт в этот отчёт не входят.
