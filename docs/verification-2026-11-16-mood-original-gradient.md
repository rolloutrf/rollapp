# Исходный отлив плиток и цвет настроения — 16 ноября 2026

Ветка `codex/combined-purchase-preview-20261116`, база `8166ccfb`. Рабочее
дерево до начала было чистым; проверки включали изменения задачи. Рецепт
сверен с `2b99474c`, последней версией до переноса настроения на плитки.

Возвращены исходный эллипс нижнего блика, точки перехода, боковое отражение,
тёмная основа активной плитки, внутренний контур и появление за 280 мс.
Цвет обоих слоёв задаёт настроение. Для нейтрального режима насыщенность
обнулена; невыбранные плитки показывают тот же отлив с меньшей интенсивностью.
При уменьшении движения фон появляется сразу, при принудительных цветах
выбранная плитка сохраняет системный Highlight.

На локальном живом предпросмотре проверены Gallup и Hogan: при смене выбора
все четыре плитки сохранили единый оттенок, размер 130×100 и границы ленты.
Производственные данные не менялись; предпросмотр оставлен запущенным.

`test:profile-mood` прошёл на девяти размерах: все пять цветов, старая
геометрия и светлота блика, единый оттенок слоёв, публичная видимость и
уменьшение движения. Просмотрен мобильный снимок после завершения анимации. Полные `test:action-rails`, `test:ui` и `npm run build`
прошли; в сборке прежнее предупреждение о размере чанков.

Полный `test:drag-drop` запущен. В проверке 320 px плитки списков, бейджи
и несколько видов переноса прошли, затем сценарий группировки карточек
остановился на ожидании подсветки цели. Полный прогон не засчитывается.
Целевой `test:drag-drop -- --list-tiles-only` прошёл все восемь размеров,
включая сравнение градиента поднятой плитки с исходным градиентом.
