# Проверка Rollapp MCP, 9 ноября 2026

## Релизный кандидат

Кандидат подготовлен на production-ветке `0365455b5ff804cd096552c62e7beacdc7e18d68`. Добавлен Streamable HTTP `/mcp`. Токены `read` и `write` имеют отдельное пространство хешей в существующей таблице `sessions`. Схема выпуска использует `verify`.

- `node --test server/mcp-http.test.js scripts/mcp/mcp.test.js` проверяет оба транспорта, версию протокола 2025-11-25, выдачу токенов, права, отказ поддельному запросу, истечение и отзыв через HTTP fixtures.
- `npm test` — 984 прошли, 1 пропущен. `npm run test:private-data`, `npm run test:private-history`, `npm run test:ui` и `npm run build` завершились успешно.
- `npm audit` и `npm audit --omit=dev` выявили 8 и 2 предупреждения. Установленный для MCP Zod 4.6.7 содержит исправление, унаследованная зависимость `@ton/ton` по-прежнему использует Zod 3.25.76.
- В CI после ответа health с точным SHA добавлена проверка HTTP `401` от `/mcp` без токена. Полный gate выпуска сохранён.
- После пополнения баланса Yandex Cloud принял запуск настроенного production PostgreSQL. Публичный `/api/healthz` снова вернул `ok=true` для предыдущего образа `0365455b5ff804cd096552c62e7beacdc7e18d68`. Перед выкладкой `initializeRuntimeDatabase` релизного кандидата подтвердил существующую схему на этом кластере через прямой TLS и `READ ONLY`.
