# Календарь и объявления в ряду действий Вишлиста

8 ноября 2026 года. База `b551d90cb5b368826f04354e4fedcbeb9254ed54`, рабочее дерево с незакоммиченными изменениями, Node 22.22.3.

«Календарь» и «Доска объявлений» перенесены из шапки личного Вишлиста в конец общего ряда действий. Ряд сохраняет прокрутку и остаётся доступен при загрузке и при ошибке списка. На публичном профиле ссылки остаются в отдельной группе.

- `npm run test:action-rails`: 153 сценария на девяти ширинах 320–1920 px, включая 820×414. Проверены общий ряд, ссылки, размеры и отступы кнопок, оба края прокрутки, вертикальная прокрутка и доступность календаря при ошибке загрузки. Просмотрены снимки десктопа и обоих концов ряда на телефоне.
- `npm run test:profile-publications` и `npm run test:profile-wishlists`: прошли полные матрицы из восьми и девяти размеров соответственно. `npm run test:page-scrollers`: 225 сценариев прошли. `npm run test:ui`, `npm run build` и `git diff --check` прошли. Сборка выдала предупреждение о размере чанка.
- `npm run dev:keepalive:status`: API и frontend готовы. Существующая production PostgreSQL проверена по TLS в режиме `verify`, без миграций и очистки. В авторизованном превью с блокировкой изменяющих HTTP-запросов проверены: один ряд из восьми кнопок 48 px на 1280 px, прокрутка и фокус на последней ссылке на 390×480, переходы в оба раздела и отдельная группа на публичном профиле. Сервис оставлен включённым.
- `npm audit`: 8 замечаний (2 высоких); `npm audit --omit=dev`: 2 высоких (`@ton/ton`, `zod`). Зависимости не менялись.

Локальный `npm run check:comprehensive` на исходной базе завершился на `calendar-sync-smoke.mjs`: после успешного сценария 768×900 тест не дождался карточки события Apple. Unit-этап прошёл (974 пройдено, 1 пропущен). Журналы: `/tmp/rollapp-f2eb-comprehensive.log` и `/tmp/rollapp-f2eb-comprehensive.json`. Реальное сенсорное устройство не проверялось.
