# Открытие подарочной карты из профиля, 14 ноября 2026

Проверяемый коммит `5d388e87842b125abbc37a14e6331234f09af6e9`,
ветка `codex/business-contact-cards-20261114`. Финальный прогон
`test:gifts` начат с чистого дерева. Основная рабочая копия и её
текущие изменения не менялись.

Регрессия воспроизведена до исправления. Когда `/rolls` отвечает ошибкой,
экран терял успешный ответ списка карт и отображал сообщение о недоступной
карте. Теперь у этих запросов независимые состояния. Выпуск не предлагается
во время открытия выбранной карты. Проверены успешная загрузка карты при
сбое кошелька, отдельный повтор `/rolls`, различие двух карт одного бизнеса,
явный выбор другой карты, очистка суммы и получателя и возврат фокуса
к исходной кнопке. Просмотрены снимки на 390×400 и 1440×400.

`npm run test:gifts`, `npm run test:ui`, `npm run build` и
`git diff --check` прошли. `npm audit` и `npm audit --omit=dev` вернули
8 и 2 записи соответственно. Зависимости не менялись.

На локальном предпросмотре сервер доступен и отдаёт новый компонент.
Read-only проверка `scripts/gift-cards-schema.mjs` с настройками основной
копии подтвердила наличие обеих таблиц в настроенной production PostgreSQL.
Браузерные проверки использовали изолированный транспорт. Выпуск, пополнение
и передача реальных карт не выполнялись.

Сценарий открытия из реального `ProfileSettingsModal` прошёл отдельно
на всех девяти размерах от 320 до 1920 px, включая 390×400 и 1440×400.
Прогон использовал проверки открытия, Back, фокуса и перехода к бизнесу
из `test:profile`. Полные прогоны `test:profile` останавливались после
проверки карт из-за тайм-аутов в сценариях синхронизации Яндекс Диска
и открытия персональной информации.
