# Единая лента предложений Вишлиста — 22 ноября 2026

Ветка `codex/unified-wishlist-offers`. База `origin/main`,
SHA `a7a1f3c7749a7ad893814b4f1b22a46745ec7a33`. Начальное дерево было чистым,
проверялся рабочий diff с незакоммиченными изменениями.

В Вишлисте активная позиция показывает название, персональную цену и срок
доставки или оказания услуги. Клик по карточке и клавиша Enter на кнопке
открывают чекаут. Подтверждение оплаты остаётся отдельным действием.
Прежние рекомендации без персонального счёта доступны в той же ленте.
URL с `view=invoices` открывает её напрямую. При восстановлении платежа
или возврата действие проверки доступно на карточке.

Сервер сохраняет срок исполнения в снимке предложения, сверяет его при
идемпотентном повторе создания и копирует в запись оформленного заказа.
Старые записи без срока показывают «уточняется у продавца».

## Production

Проверен локальный предпросмотр `127.0.0.1:15172` с production PostgreSQL.
`npm run dev:keepalive:status` сообщил готовность API и frontend. Сервис
запущен в режиме `verify` по прямому TLS и оставлен работать. В живой сессии
показалось пустое состояние единой ленты без вкладок и API-ошибок.
Запросы читающих маршрутов списка и рекомендаций проверены на production
в транзакциях READ ONLY. Пользовательские записи и платежи не создавались.

`node scripts/personal-offers-schema.mjs --check` подтвердил целевую БД
`rollapp`, роль `rollapp_app` и отсутствие колонки `fulfillment_terms`.
Для записи новых сроков нужна отдельно согласованная миграция
`--apply-fulfillment`. Миграция и выпуск не выполнялись. Запись и чтение
новых условий на production и реальное списание остаются непроверенными.
