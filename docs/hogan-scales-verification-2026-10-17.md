## Результат

На странице Hogan отображаются исходные процентильные полосы и сегменты
подшкал. Для указанного пользователем PDF восстановлены 28 основных значений,
125 строк подшкал и 500 сегментов. Все 28 значений сверены с приложенным
изображением; цветные сегменты сравниваются с извлечённой графикой PDF.
Нейтральные ячейки адаптируются к теме. Шкалы не вычисляются из интерпретаций.

На телефоне подпись/число стоят над полосой, три профиля подшкал идут друг
за другом; выше 820px подшкалы используют три колонки. Длинные названия полностью
переносятся, основной текст сохраняет Geist 18/28. Имена графики доступны
скринридеру. Повторная загрузка оригинала не требуется: API разбирает прежний
layout для ответа без записи в production.

Для границ 0/37/100 и пустых/полных наборов из четырёх/пяти сегментов добавлен
отдельный smoke, включённый в `test:identity-reports`. Реальные данные не включены
в fixtures: они проверены отдельным локальным read-only прогоном.
Контракт: [identity-report-charts.md](identity-report-charts.md).
