# Rollapp для iOS

Вишлист, карточки, группы, формы, список друзей и просмотр профилей реализованы на SwiftUI. На экранах используется исходная композиция Rollapp с тёмным фоном, логотипом, Geist Variable, горизонтальными плитками и сеткой обложек. Управляющие элементы используют монохромную палитру. На iOS 26 и новее Liquid Glass применяется к кнопкам «Сферы», «Поделиться» и «Добавить» на основном экране вишлиста.

iOS-клиент читает и сохраняет данные через API [роллапп.рф](https://роллапп.рф). Из переключателя сфер доступны «Идентичность», «Здоровье», «Образование», «Карьера», «Планирование» и «Роллы». Сферы, лента, каталоги и магазин показывают действующие страницы Rollapp во встроенном WebKit с общей сессией. Содержимое сфер определяется правами аккаунта. Вход через Яндекс ID также проходит внутри приложения. Сторонние ссылки HTTP и HTTPS открываются в отдельном встроенном окне с изолированной сессией.

## Сборка для симулятора

Нужны Xcode с платформой iOS и установленный runtime симулятора. Минимальная версия системы приложения — iOS 17. Откройте `ios/Rollapp.xcodeproj`, выберите схему **Rollapp** и запустите её на симуляторе iPhone или iPad.

Из корня репозитория можно собрать приложение командой

```sh
xcodebuild -project ios/Rollapp.xcodeproj -scheme Rollapp \
  -configuration Debug -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath ios/build/simulator build
```

Готовый пакет появится в `ios/build/simulator/Build/Products/Debug-iphonesimulator/Rollapp.app`.

## Запуск на iPhone

Добавьте Apple Account в Xcode, выберите свою команду в **Signing & Capabilities** у цели Rollapp и запустите схему на подключённом iPhone. Идентификатор пакета по умолчанию — `rf.rollapp.ios`. Для распространения через TestFlight нужен архив, подписанный командой Apple Developer.
